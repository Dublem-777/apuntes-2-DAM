## Instalación y configuración de Java

Para instalar Java, consulta la página oficial de descargas de Oracle: [https://www.oracle.com/es/java/technologies/downloads/](https://www.oracle.com/es/java/technologies/downloads/). Descarga la versión adecuada para el sistema operativo y la arquitectura.

Después de instalarlo, añade al `PATH` el directorio que contiene los ejecutables de Java (`java`, `javac`, `jar`, etc.). La ruta depende del sistema operativo y del método de instalación. Vídeos de referencia:

- Windows: [tutorial](https://www.youtube.com/watch?v=RgNW4OkNPzM)
- Linux: [tutorial](https://www.youtube.com/watch?v=zDxXaByZdeI)
- macOS con Apple Silicon M1/M2: [tutorial](https://www.youtube.com/watch?v=n15tOYj6d4E)

## Compilación, ejecución y empaquetado

El flujo clásico de un programa Java es escribir fuentes `.java`, compilarlas a bytecode `.class` y, si conviene, empaquetar clases y recursos en un JAR.

```sh
javac Programa.java
java Programa
```

Para crear un JAR ejecutable hace falta indicar su clase principal en el manifiesto (`META-INF/MANIFEST.MF`):

```text
Main-Class: NombreClaseMain
```

El manifiesto debe terminar con un salto de línea. Se puede construir el JAR desde el directorio que contiene los `.class` y el manifiesto:

```sh
jar cfm programa.jar META-INF/MANIFEST.MF *.class
java -jar programa.jar
```

`c` crea el archivo, `f` indica su nombre y `m` especifica el manifiesto. Añade al comando los recursos que necesite la aplicación. `jar tf programa.jar` permite listar su contenido.

Para una clase sencilla, el comando correcto es `java NombreClase`, sin extensión `.class`.

## Ejecución directa de archivos fuente

Desde Java 11, el launcher puede ejecutar un archivo fuente directamente, sin una compilación explícita:

```sh
java Main.java
```

Java 22 amplió el modo de archivos fuente para programas formados por varios archivos. Por ejemplo, si las dependencias están en la carpeta `Lib`:

```sh
java -cp "Lib/*" Main.java
```

Las clases fuente deben respetar la estructura de paquetes. Esta modalidad resulta útil para ejemplos y programas pequeños; proyectos mayores suelen usar compilación y herramientas de construcción.

## Creación de JAR desde un IDE

Los IDE pueden generar JARs ejecutables. En Eclipse se puede usar **Export... > Java > Runnable JAR file**, elegir la configuración de ejecución, el destino y cómo tratar las bibliotecas. En IntelliJ IDEA se configura un artefacto desde **File > Project Structure > Artifacts**, normalmente con **JAR > From modules with dependencies**, y después se construye desde **Build > Build Artifacts**.

La opción para las dependencias determina cómo se distribuyen las bibliotecas externas. Comprueba siempre el manifiesto y prueba el resultado con `java -jar programa.jar`.

- Eclipse: [vídeo de compilación y JAR](https://www.youtube.com/embed/NYlpXTCHp5U?si=JDViPWR4ToqvgKUG)
- IntelliJ IDEA: [vídeo de creación de JAR](https://www.youtube.com/embed/d1CT7_WZGB8?si=b-6dMQDlu0tnpM-w)

## Argumentos de línea de comandos

Los argumentos pasados después del nombre de clase o de `-jar` llegan como cadenas al array `String[] args` del método `main`. El primer argumento ocupa `args[0]`; `args.length` indica cuántos se recibieron. Convierte explícitamente los valores que no sean texto y valida tanto la cantidad como el formato.

```sh
java Programa arg1 arg2
java -jar programa.jar arg1 arg2
```

Ejemplo: un argumento numérico debe convertirse con `Integer.parseInt`, gestionando `NumberFormatException`.

## Redirección de entrada y salida

La shell puede conectar los flujos estándar con archivos:

```sh
java MiClase < entrada.txt
java MiClase > salida.txt
java MiClase >> salida.txt
java MiClase 2> errores.txt
java MiClase 2>> errores.txt
```

`<` redirige `System.in`; `>` crea o sobrescribe el archivo de salida; `>>` añade al final. `2>` y `2>>` redirigen `System.err`.

Una tubería conecta la salida estándar de un proceso con la entrada estándar del siguiente:

```sh
java Programa1 | java Programa2
```

Los dos procesos pueden ejecutarse concurrentemente. Si una tubería se llena, el escritor puede bloquearse hasta que el lector consuma datos; si no hay datos disponibles, el lector espera. `System.err` no se canaliza por defecto. En Bash, el estado del pipeline suele ser el del último comando, salvo que se active `pipefail`.

## Esquema

- `PATH` permite invocar los ejecutables Java desde cualquier directorio.
- Flujo tradicional: `.java` → `javac` → `.class` → `java`; un JAR ejecutable requiere `Main-Class` en el manifiesto.
- Desde Java 11 se pueden ejecutar fuentes directamente; Java 22 amplía esta modalidad a programas con varios archivos.
- Los argumentos de `main` son `String[]`; valida cantidad y conversión.
- Las redirecciones conectan `stdin`, `stdout` y `stderr` con archivos; `|` conecta procesos.
