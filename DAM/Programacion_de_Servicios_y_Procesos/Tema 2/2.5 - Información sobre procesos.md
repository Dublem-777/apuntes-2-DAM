## Información del proceso representado por Process

`Process` representa un proceso iniciado por la aplicación. Métodos informativos importantes:

- `pid()`: identificador del proceso (Java 9+).
- `info()`: devuelve un `ProcessHandle.Info` con datos disponibles del proceso (Java 9+).
- `isAlive()`: indica si sigue ejecutándose.
- `exitValue()`: devuelve el código de salida cuando ya terminó.
- `children()` y `descendants()` (Java 9+): flujos de handles de procesos hijos directos y descendientes.

`toHandle()` permite obtener el `ProcessHandle` asociado. La disponibilidad de datos depende del sistema operativo, permisos y soporte; los valores de `ProcessHandle.Info` se representan como `Optional` y deben consultarse con operaciones como `orElse` o `ifPresent`.

## ProcessHandle.Info

`ProcessHandle.Info` puede proporcionar:

| Método | Información |
|---|---|
| `arguments()` | Argumentos del proceso, si están disponibles |
| `command()` | Ejecutable |
| `commandLine()` | Línea de comando |
| `startInstant()` | Instante de inicio |
| `totalCpuDuration()` | Tiempo de CPU acumulado |
| `user()` | Usuario asociado |

No todos los sistemas exponen todos los datos. Comprueba cada `Optional` antes de usar su valor.

## Consultar procesos del sistema

`ProcessHandle.current()` representa el proceso actual; `ProcessHandle.of(pid)` busca un proceso por PID y devuelve `Optional<ProcessHandle>`. `ProcessHandle.allProcesses()` proporciona un flujo de procesos visibles para la aplicación.

Un `ProcessHandle` también permite consultar `pid()`, `info()`, `isAlive()`, `parent()`, `children()` y `descendants()`, y ofrece operaciones de terminación y `onExit()`. Estas operaciones están sujetas a disponibilidad y permisos del sistema operativo. Limita las consultas a procesos que realmente necesites inspeccionar.

## Esquema

- `Process` representa una ejecución; `pid`, `info`, `isAlive` y `exitValue` permiten consultarla.
- `ProcessHandle` (Java 9+) permite consultar proceso actual, procesos visibles, padre e hijos.
- Los datos de `ProcessHandle.Info` son opcionales y dependen de plataforma y permisos.
