# 2.E2 · Listar archivos con Runtime

> [!info] Origen
> [[DAM/Programacion_de_Servicios_y_Procesos/Indice|Programación de Servicios y Procesos]] · Tema 2: Gestión de procesos · [[2.Repaso - Ejercicio filtro con subproceso|Ejercicio relacionado]]

## Enunciado

Escribe un programa en Java que utilice la clase `Runtime` para ejecutar un comando del sistema operativo que liste los archivos en el directorio actual. En Windows, la orden del sistema operativo para listar es `dir /a` y en Linux y macOS es `ls -la`.

El programa debe ser capaz de detectar en qué sistema operativo se está ejecutando.

## Solución

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;
import java.nio.charset.Charset;
import java.util.Locale;

public class ListarArchivosConRuntime {

    public static void main(String[] args) {
        String osName = System.getProperty("os.name").toLowerCase(Locale.ROOT);
        boolean isWindows = osName.contains("win");

        // En Windows, dir es un comando interno de cmd.exe, no un ejecutable independiente.
        String[] command = isWindows
                ? new String[]{"cmd.exe", "/c", "dir", "/a"}
                : new String[]{"ls", "-la"};

        try {
            Process process = Runtime.getRuntime().exec(command);

            // Combina salida estándar y errores para no dejar un flujo del proceso sin leer.
            try (BufferedReader reader = new BufferedReader(
                    new InputStreamReader(process.getInputStream(), Charset.defaultCharset()));
                 BufferedReader errorReader = new BufferedReader(
                         new InputStreamReader(process.getErrorStream(), Charset.defaultCharset()))) {

                System.out.println("Sistema operativo: " + System.getProperty("os.name"));
                System.out.println("Comando ejecutado: " + String.join(" ", command));
                System.out.println("Contenido del directorio actual:");

                String line;
                while ((line = reader.readLine()) != null) {
                    System.out.println(line);
                }

                while ((line = errorReader.readLine()) != null) {
                    System.err.println(line);
                }
            }

            int exitCode = process.waitFor();
            if (exitCode != 0) {
                System.err.println("El comando terminó con código de salida " + exitCode);
            }
        } catch (IOException e) {
            System.err.println("No se pudo ejecutar el comando: " + e.getMessage());
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            System.err.println("Se interrumpió la espera del comando.");
        }
    }
}
```

### Cómo funciona

1. `System.getProperty("os.name")` devuelve el nombre del sistema operativo. Se convierte a minúsculas para comparar sin distinguir mayúsculas.
2. En Windows se ejecuta `cmd.exe /c dir /a`: `dir` es un comando interno del intérprete, por eso `Runtime` necesita que lo invoque `cmd.exe`. En Linux y macOS se ejecuta `ls -la`.
3. `Runtime.getRuntime().exec(String[])` inicia el comando como subproceso. Cada elemento del array es un argumento distinto; no se interpreta como una cadena única por el shell.
4. `getInputStream()` permite leer la salida estándar del subproceso; `getErrorStream()` recoge sus errores.
5. `waitFor()` espera a que termine y devuelve su código de salida. Si la espera se interrumpe, se restaura la marca de interrupción del hilo.

> [!warning] Directorio de trabajo
> El comando lista el directorio de trabajo desde el que se inicia la aplicación Java, que puede ser distinto de la carpeta donde está guardado el archivo `.java`.
