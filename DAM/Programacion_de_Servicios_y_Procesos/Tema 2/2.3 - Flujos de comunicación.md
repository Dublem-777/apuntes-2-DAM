## Flujos predeterminados entre padre e hijo

Al iniciar un subproceso, sus flujos estándar se conectan por defecto a tuberías (`PIPE`) con el proceso padre:

| Flujo del hijo | Acceso desde `Process` del padre | Dirección |
|---|---|---|
| `stdin` | `getOutputStream()` | Padre → hijo |
| `stdout` | `getInputStream()` | Hijo → padre |
| `stderr` | `getErrorStream()` | Hijo → padre |

Los nombres de los métodos se entienden desde la perspectiva del padre. Por tanto, el padre escribe en `getOutputStream()` para alimentar la entrada del hijo y lee `getInputStream()` para recibir su salida.

## Lectura y escritura de datos

Es posible envolver los flujos de bytes en lectores y escritores de texto. Conviene indicar charset explícito cuando el protocolo lo requiera y cerrar el flujo de entrada del hijo cuando el padre haya terminado de enviar datos.

```java
Process proceso = new ProcessBuilder("programa").start();
try (BufferedWriter entrada = new BufferedWriter(
        new OutputStreamWriter(proceso.getOutputStream(), StandardCharsets.UTF_8))) {
    entrada.write("datos para el hijo");
    entrada.newLine();
}
try (BufferedReader salida = new BufferedReader(
        new InputStreamReader(proceso.getInputStream(), StandardCharsets.UTF_8))) {
    String linea;
    while ((linea = salida.readLine()) != null) {
        System.out.println(linea);
    }
}
```

Las operaciones de E/S pueden bloquearse cuando no hay datos o el búfer está lleno. Si el padre necesita hacer otras tareas mientras espera, puede delegar la lectura a otro hilo. `try-with-resources` cierra automáticamente recursos `AutoCloseable`.

> [!warning] Evitar interbloqueos por tuberías
> Si el hijo llena `stdout` o `stderr` y el padre no lee, el hijo puede bloquearse. Si el padre espera al hijo con `waitFor()` sin consumir sus salidas, ambos pueden quedar bloqueados. Lee ambos flujos concurrentemente, combínalos o redirígelos según corresponda.

## Codificación de caracteres

Los flujos transportan bytes; texto del padre e hijo debe usar una codificación compatible. La codificación de la consola puede variar según sistema y configuración. Evita asumir una página de códigos universal: especifica charset en ambos extremos cuando controles el programa y adapta la lectura a la codificación real de un comando externo.

## Redirección de los flujos

`ProcessBuilder` permite configurar flujos antes de `start()` mediante `redirectInput`, `redirectOutput` y `redirectError`. Opciones frecuentes de `ProcessBuilder.Redirect`:

- `PIPE`: tubería hacia/desde el padre; valor predeterminado.
- `INHERIT`: comparte el flujo correspondiente del padre.
- `DISCARD`: descarta la salida.
- `from(file)`, `to(file)` y `appendTo(file)`: lee desde un archivo, escribe/sobrescribe o añade al final.

`inheritIO()` hereda entrada, salida y error. Con `redirectErrorStream(true)`, `stderr` se combina con `stdout`; el flujo combinado se lee mediante `getInputStream()`.

```java
Process proceso = new ProcessBuilder("ls", "-la")
        .redirectOutput(new File("salida.txt"))
        .redirectError(ProcessBuilder.Redirect.INHERIT)
        .start();
```

## Creación de pipelines

Desde Java 9, `ProcessBuilder.startPipeline(List<ProcessBuilder>)` inicia una lista de procesos conectando la salida estándar de cada uno con la entrada estándar del siguiente. Devuelve una lista de `Process` en el mismo orden.

Se puede configurar la entrada del primero y la salida del último. Los flujos internos forman parte del pipeline y no se redirigen individualmente. Los procesos se ejecutan concurrentemente, como en una tubería de shell.

## Otras alternativas de comunicación

Además de los flujos estándar, los procesos pueden comunicarse mediante sockets. JNI permite integrar Java con código nativo; bibliotecas específicas también pueden proporcionar memoria compartida, tuberías o semáforos.

## Esquema

- Los tres flujos estándar conectan padre e hijo mediante tuberías por defecto.
- Desde el padre: `getOutputStream()` escribe al `stdin` del hijo; `getInputStream()` lee su `stdout`.
- E/S puede bloquearse; consumir stdout y stderr evita interbloqueos por búfer lleno.
- El charset debe coincidir en ambos extremos.
- `ProcessBuilder` permite heredar, descartar, combinar o redirigir flujos antes de iniciar el proceso.
- `startPipeline` conecta varios procesos en cadena.
