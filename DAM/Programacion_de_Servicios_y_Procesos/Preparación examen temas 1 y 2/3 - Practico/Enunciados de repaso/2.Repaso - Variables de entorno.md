Crea un _programa_ simple (ContextInfo) que primero imprime el valor de una variable de entorno específica CUSTOM_ID, después ejecuta el comando pwd (si está en Linux/macOS) o el comando cd (si está en Windows) para imprimir el directorio de trabajo actual. Finalmente ejecuta el comando ls (si está en Linux/macOS) o dir (si está en Windows) en el directorio de trabajo para listar su contenido.  
Por su parte, el programa Java principal debe establecer como directorio de trabajo del subproceso el directorio /tmp/ (si está en Linux/Mac) o C:\Temp\ (si está en Windows). Además debe establecer la variable de entorno CUSTOM_ID para el subproceso con un valor único (por ejemplo el _timestamp_ actual). Finalmente debe lanzar el subproceso ContextInfo. Posteriormente debe capturar la salida completa del subproceso y verificar el valor de CUSTOM_ID es el que se inyectó en el subproceso y que el directorio de trabajo impreso por el _ContextInfo_ es el que se estableció para el subproceso.
