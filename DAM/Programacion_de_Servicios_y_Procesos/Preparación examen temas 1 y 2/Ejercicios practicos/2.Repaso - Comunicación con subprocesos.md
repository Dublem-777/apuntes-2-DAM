En este ejercicio tienes que realizar dos programas complementarios:  
1. Realiza un programa llamado language.jar que reciba como argumento el número de palabras "inventadas" que debe enviar a  
salida estándar, una palabra en cada línea. Cada palabra debe tener un número aleatorio de entre 2 y 8 caracteres, y las letras que la conforman también deben elegirse aleatoriamente de entre las letras minúsculas del idioma inglés.  
Si el programa no recibe ningún argumento o el número de palabras recibido no es mayor que 0 el programa mostrará por la  
salida de error un mensaje de uso correcto y retornará el valor 1. Si el programa funciona correctamente retornará el  
valor 0.  
2. Crea un programa dictionary.jar, que lance 10 instancias del programa language.jar, presuponiendo que éste se encuentra en el mismo directorio del propio programa dictionary. En cada llamada al programa language se debe propocionar el número de palabras que debe generar. En la primera instancia se deberá generar 1 palabra, en la segunda 2, y así sucesivamente, hasta la última instancia en la que se debe solicitar la generación de 10 palabras. Todas las instancias de language.jar deben estar ejecutándose a la vez.   
Una vez lanzadas, el programa dictionary.jar debe mostrar un mensaje por pantalla diciendo "Generando todas las palabras para el diccionario...".  
Si alguna de las instancias de language.jar finalizara con error se deberá mostrar por pantalla la salida de error producida por dicha instancia y no realizar ninguna acción adicional.Una vez se hayan generado todas las palabras correctamente, el programa dictionary.jar debe  crear una lista de cadenas con todas las palabras generadas para el diccionario.Finalmente, deberá filtrar todas las palabras del diccionario para que no haya palabras repetidas, y mostrarlas por pantalla, una palabra en cada línea.
