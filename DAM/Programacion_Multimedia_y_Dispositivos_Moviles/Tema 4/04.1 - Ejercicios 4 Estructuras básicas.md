## Ejercicio 4.1 · Clasificación por edad e ingresos con `if`

> [!question] Enunciado
> Escribe un programa que solicite una edad y unos ingresos anuales y muestre la categoría de la persona según estos criterios:
>
> - Menos de 18 años: **«Menor de edad»**.
> - Entre 18 y 64 años:
>   - Menos de 20.000: **«Joven trabajador con bajo ingreso»**.
>   - Desde 20.000 hasta 60.000: **«Adulto trabajador con ingreso medio»**.
>   - Más de 60.000: **«Adulto trabajador con alto ingreso»**.
> - 65 años o más:
>   - Menos de 15.000: **«Anciano con bajo ingreso»**.
>   - Desde 15.000 hasta 40.000: **«Anciano con ingreso medio»**.
>   - Más de 40.000: **«Anciano con alto ingreso»**.
>
> Resuelve la clasificación usando `if` y condiciones anidadas. Define cómo tratar exactamente los valores límite para que no queden casos sin clasificar.

### Clases y métodos introducidos
- `readln()`: lee una línea de la entrada estándar y devuelve un `String`.
- `String.toInt()` y `String.toDouble()`: convierten texto a número; texto no válido produce `NumberFormatException`.
- `if` / `else if` / `else`: selección condicional; se pueden anidar.
- `&&`: AND lógico con cortocircuito.
- *String templates*: `$variable` y `${expresion}` insertan valores en una cadena.

> **Términos explicados:** [[01 - Introduccion a Kotlin#6. Entrada desde consola|`readln()` y conversiones de entrada]] · [[04 - Estructuras básicas#1. La estructura `if`|`if` anidado y `else if`]] · [[02 - Jerarquia de tipos#5. Booleanos|operadores lógicos]] · [[01 - Introduccion a Kotlin#5. Variables|interpolación de cadenas]]

#### Ejemplo simple de funcionamiento
```kotlin
val edad = 25
val categoria = if (edad >= 18) "Mayor de edad" else "Menor de edad"
println(categoria)
```

### Código fuente (`Ejercicio4.1/src/Main.kt`)

```kotlin
fun main() {
    print("Introduce la edad: ")
    val edad = readln().toInt()

    print("Introduce los ingresos anuales: ")
    val ingresos = readln().toDouble()

    val categoria = if (edad < 18) {
        "Menor de edad"
    } else if (edad < 65) {
        if (ingresos < 20_000.0) {
            "Joven trabajador con bajo ingreso"
        } else if (ingresos <= 60_000.0) {
            "Adulto trabajador con ingreso medio"
        } else {
            "Adulto trabajador con alto ingreso"
        }
    } else {
        if (ingresos < 15_000.0) {
            "Anciano con bajo ingreso"
        } else if (ingresos <= 40_000.0) {
            "Anciano con ingreso medio"
        } else {
            "Anciano con alto ingreso"
        }
    }

    println("Categoría: $categoria")
}
```

### Explicación paso a paso
1. `readln()` obtiene cada dato como texto; `toInt()` convierte la edad y `toDouble()` permite representar ingresos con decimales.
2. El primer `if` separa a menores de edad. Si tiene 18 años o más, `else if (edad < 65)` distingue el tramo de 18 a 64 años; el `else` cubre 65 o más.
3. Dentro de cada tramo de edad, otro `if` compara los ingresos en orden ascendente.
4. Los límites quedan cubiertos sin huecos: 20.000 y 60.000 pertenecen al intervalo medio adulto; 15.000 y 40.000, al intervalo medio de 65 años o más.
5. La última rama seleccionada se guarda en `categoria` y se imprime mediante interpolación.

## Ejercicio 4.2 · Clasificar edades con `when` sin sujeto

> [!question] Enunciado
> Solicita una edad y clasifícala con un `when` sin sujeto, usado como alternativa a una cadena `if`/`else if`. Muestra en qué rango está: de 1 a 10, de 11 a 20, de 21 a 30, de 31 a 40, de 41 a 50 o más de 50.

### Clases y métodos introducidos
- `when { condicion -> resultado }`: comprueba condiciones booleanas en orden y ejecuta la primera verdadera.
- `in`: comprueba que un valor pertenece a un rango inclusivo como `1..10`.
- `else`: rama predeterminada, útil para valores no contemplados.
- `readln().toInt()`: lee una edad desde la consola.

> **Términos explicados:** [[04 - Estructuras básicas#2. `when` como selección de condiciones|`when` sin sujeto y condiciones]] · [[02 - Jerarquia de tipos#4. Rangos y progresiones|rangos y operador `in`]]

#### Ejemplo simple de funcionamiento
```kotlin
val nota = 8
val resultado = when {
    nota >= 5 -> "Aprobado"
    else -> "Suspenso"
}
println(resultado)
```

### Código fuente (`Ejercicio4.2/src/Main.kt`)

```kotlin
fun main() {
    print("Introduce una edad: ")
    val edad = readln().toInt()

    val rango = when {
        edad in 1..10 -> "de 1 a 10"
        edad in 11..20 -> "de 11 a 20"
        edad in 21..30 -> "de 21 a 30"
        edad in 31..40 -> "de 31 a 40"
        edad in 41..50 -> "de 41 a 50"
        edad > 50 -> "mayor de 50"
        else -> "fuera del rango solicitado"
    }

    println("La edad está $rango")
}
```

### Explicación paso a paso
1. Se lee la edad una sola vez y se guarda en `edad`.
2. `when` no recibe sujeto: cada rama contiene una expresión booleana completa.
3. Los rangos `1..10`, `11..20` y siguientes incluyen ambos extremos. Como no se solapan, cada edad válida cae en una única rama.
4. `edad > 50` cubre valores a partir de 51; `else` informa de edades inferiores a 1.
5. El `when` se usa como expresión para asignar la descripción a `rango`.

## Ejercicio 4.3 · Clasificar edades con `when` con sujeto

> [!question] Enunciado
> Solicita una edad y clasifícala con un `when` con sujeto, usando comprobaciones de pertenencia a rangos. Muestra si está entre 1 y 10, 11 y 20, 21 y 30, 31 y 40, 41 y 50, o por encima de 50.

### Clases y métodos introducidos
- `when (valor) { ... }`: compara un sujeto con los casos indicados en sus ramas.
- `in rango`: comprueba pertenencia al rango; `1..10` incluye 1 y 10.
- `else`: gestiona los valores que no coinciden con ninguna rama.

> **Términos explicados:** [[04 - Estructuras básicas#3. `when` con sujeto|`when` con sujeto y ramas]] · [[02 - Jerarquia de tipos#4. Rangos y progresiones|rangos y operador `in`]]

#### Ejemplo simple de funcionamiento
```kotlin
val dia = 6
val tipo = when (dia) {
    1, 7 -> "fin de semana"
    in 2..6 -> "día laborable"
    else -> "día no válido"
}
println(tipo)
```

### Código fuente (`Ejercicio4.3/src/Main.kt`)

```kotlin
fun main() {
    print("Introduce una edad: ")
    val edad = readln().toInt()

    val rango = when (edad) {
        in 1..10 -> "de 1 a 10"
        in 11..20 -> "de 11 a 20"
        in 21..30 -> "de 21 a 30"
        in 31..40 -> "de 31 a 40"
        in 41..50 -> "de 41 a 50"
        else -> if (edad > 50) "mayor de 50" else "fuera del rango solicitado"
    }

    println("La edad está $rango")
}
```

### Explicación paso a paso
1. `when (edad)` evalúa el sujeto `edad` una vez.
2. Cada rama `in ...` pregunta si ese valor está dentro del rango correspondiente.
3. Los intervalos consecutivos evitan huecos y solapamientos entre edades de 1 a 50.
4. La rama `else` cubre tanto edades superiores a 50 como valores menores que 1; un `if` pequeño los distingue.
5. Al asignar el resultado del `when` a `rango`, todas las posibilidades tienen que devolver un texto.

## Ejercicio 4.4 · Expresión `when` sobre `Any?`

> [!question] Enunciado
> Completa la función `name` para que devuelva:
>
> - `"Nothing"` si recibe `null`.
> - `"Small number"` si recibe `1`, `2` o `3`.
> - `"Magic number"` si recibe `7` o `13`.
> - `"Big number"` si recibe un número entre `4` y `100`.
> - `"String"` si recibe un `String`.
> - `"Integer"` si recibe un `Int` o un `Long`.
> - `"No idea"` en cualquier otro caso.
>
> Usa una expresión `when` con `a` como sujeto y firma `fun name(a: Any?): String`. Prueba la función con valores que cubran todas las ramas.

### Clases y métodos introducidos
- `Any?`: tipo que admite cualquier objeto Kotlin y también `null`.
- `when (valor)`: selección por igualdad, rango o tipo.
- `is Number` y `is String`: comprobaciones de tipo; permiten *smart cast* dentro de la rama.
- `Number.toDouble()`: normaliza los tipos numéricos para compararlos con un mismo rango.
- `in 4.0..100.0`: comprueba pertenencia a un rango inclusivo.
- `arrayOf<Any?>`: crea una colección de pruebas con valores de tipos distintos y nulos.

> **Términos explicados:** [[04 - Estructuras básicas#4. `when` como expresión|`when` como expresión]] · [[02 - Jerarquia de tipos#9. Los tipos Any y Any?|`Any?`]] · [[02 - Jerarquia de tipos#11. Comprobación de tipo|comprobación `is` y smart cast]]

#### Ejemplo simple de funcionamiento
```kotlin
fun describir(valor: Any?): String = when (valor) {
    null -> "nulo"
    is String -> "texto de ${valor.length} caracteres"
    is Int -> "entero"
    else -> "otro valor"
}
```

### Código fuente (`Ejercicio4.4/src/Main.kt`)

```kotlin
fun name(a: Any?): String = when (a) {
    null -> "Nothing"
    is Number -> {
        val number = a.toDouble()
        when (number) {
            1.0, 2.0, 3.0 -> "Small number"
            7.0, 13.0 -> "Magic number"
            in 4.0..100.0 -> "Big number"
            else -> if (a is Int || a is Long) "Integer" else "No idea"
        }
    }
    is String -> "String"
    else -> "No idea"
}

fun main() {
    val values: Array<Any?> = arrayOf(
        null, 1, 2, 3, 7, 13, 4, 100, 42L, "Kotlin", 3.14, 101L, 120.5,
    )

    for (value in values) {
        println("$value → ${name(value)}")
    }
}
```

### Explicación paso a paso
1. La primera rama distingue `null`, antes de intentar comprobar ningún tipo.
2. Si el valor es `Number`, el *smart cast* permite llamar a `toDouble()` y aplicar un solo `when` numérico a `Int`, `Long`, `Double` y otros tipos numéricos.
3. Se comprueban primero los valores especiales `1`, `2`, `3`, `7` y `13`; después, el rango inclusivo de 4 a 100.
4. Fuera de esos casos, solo `Int` y `Long` reciben `"Integer"`; los demás números reciben `"No idea"`. Así se distingue el tipo además del valor.
5. El bucle recorre datos heterogéneos y muestra tanto cada valor como el resultado de `name`.

## Ejercicio 4.5 · Descuentos con condiciones de guarda

> [!question] Enunciado
> Define `calculateDiscount`, que reciba `orderTotal: Double` e `isLoyalCustomer: Boolean` y devuelva un `String` con el descuento aplicado.
>
> Usa una expresión `when` con `orderTotal` como sujeto y condiciones de guarda para aplicar, en este orden:
>
> - Si `orderTotal` es menor que `10.0`, devuelve `"No discount"`.
> - Si `orderTotal` es menor que `50.0` y `isLoyalCustomer` es `true`, devuelve `"5% Loyalty Discount"`.
> - Con una rama `else if`, si `orderTotal` es menor que `100.0`, devuelve `"10% Standard Discount"`, sin tener en cuenta la lealtad.
> - En cualquier otro caso, devuelve `"20% Volume Discount"`.
>
> En `main`, llama a la función al menos tres veces para probar distintas ramas e imprime los resultados.

### Clases y métodos introducidos
- Expresión `when` con sujeto: permite seleccionar un resultado según el valor de `orderTotal`.
- Condición de guarda: `caso if condicion -> resultado` exige que coincidan el caso y la guarda.
- Rama `else if condicion -> resultado`: añade una condición final al `when` con sujeto.
- `Double`: tipo numérico con decimales.
- **Requisito de versión:** la sintaxis de guardas requiere Kotlin 2.2 o posterior.

> **Términos explicados:** [[04 - Estructuras básicas#5. Condiciones de guarda en `when`|condiciones de guarda en `when`]] · [[04 - Estructuras básicas#4. `when` como expresión|`when` como expresión]]

#### Ejemplo simple de funcionamiento
```kotlin
fun etiqueta(esAdmin: Boolean): String = when (true) {
    true if esAdmin -> "administrador"
    else -> "usuario"
}
```

### Código fuente (`Ejercicio4.5/src/Main.kt`)

```kotlin
fun calculateDiscount(orderTotal: Double, isLoyalCustomer: Boolean): String =
    when (orderTotal) {
        else if orderTotal < 10.0 -> "No discount"
        in 10.0..<50.0 if isLoyalCustomer -> "5% Loyalty Discount"
        else if orderTotal < 100.0 -> "10% Standard Discount"
        else -> "20% Volume Discount"
    }

fun main() {
    println(calculateDiscount(8.0, true))
    println(calculateDiscount(25.0, true))
    println(calculateDiscount(25.0, false))
    println(calculateDiscount(120.0, false))
}
```

### Explicación paso a paso
1. Las ramas se evalúan en orden. La primera guarda cubre cualquier importe inferior a 10, también si es negativo.
2. `in 10.0..<50.0` comprueba el intervalo desde 10 incluido hasta 50 excluido. La guarda añade la condición de que el cliente sea leal.
3. Si no se cumple la rama de fidelidad, `else if orderTotal < 100.0` aplica el descuento estándar sin consultar `isLoyalCustomer`.
4. `else` cubre importes de 100 o más y devuelve el descuento por volumen.
5. La expresión `when` devuelve directamente el texto de descuento. Este ejemplo usa guardas, así que necesita un compilador Kotlin compatible.

## Ejercicio 4.6 · Árbol de Navidad con bucles

> [!question] Enunciado
> Solicita un entero que indique la altura del árbol en filas y dibuja un árbol de Navidad usando bucles, **sin utilizar `repeat`**. La última fila siempre debe ser la base del árbol y contener tres asteriscos.
>
> Para una altura de `5`, dibuja cuatro filas de copa, con `1`, `3`, `5` y `7` asteriscos, seguidas por una base de `3` asteriscos.

### Clases y métodos introducidos
- `for (indice in rango)`: repite un bloque para cada valor de un rango.
- `0 until limite`: rango que incluye el límite inferior y excluye el superior.
- `print()` y `println()`: imprimen texto; `println()` añade un salto de línea.
- Funciones propias `imprimirEspacios()` e `imprimirAsteriscos()`: encapsulan tareas repetidas.

> **Términos explicados:** [[04 - Estructuras básicas#6. Bucles `for` y `repeat`|bucle `for` y rangos de iteración]] · [[03 - Funciones#1. Definición de funciones|funciones auxiliares]]

#### Ejemplo simple de funcionamiento
```kotlin
for (cantidad in 1..3) {
    print("*")
}
println() // ***
```

### Código fuente (`Ejercicio4.6/src/Main.kt`)

```kotlin
fun imprimirEspacios(cantidad: Int) {
    for (i in 0 until cantidad) print(" ")
}

fun imprimirAsteriscos(cantidad: Int) {
    for (i in 0 until cantidad) print("*")
}

fun main() {
    print("Altura del árbol: ")
    val altura = readln().toInt()
    require(altura >= 1) { "La altura debe ser al menos 1" }

    // La altura incluye las filas de copa y la base.
    for (fila in 0 until altura - 1) {
        imprimirEspacios(altura - fila - 2)
        imprimirAsteriscos(fila * 2 + 1)
        println()
    }

    // Centra la base de tres asteriscos bajo la copa.
    val espaciosBase = if (altura > 3) altura - 3 else 0
    imprimirEspacios(espaciosBase)
    imprimirAsteriscos(3)
    println()
}
```

### Explicación paso a paso
1. La altura cuenta todas las filas, incluida la base; por tanto, el bucle recorre `altura - 1` filas de copa.
2. En cada fila, `fila * 2 + 1` calcula la cantidad impar de asteriscos: 1, 3, 5, 7…
3. Los espacios iniciales decrecen una unidad por fila para centrar la copa. Las dos funciones auxiliares imprimen carácter a carácter usando `for`, sin `repeat`.
4. La base imprime siempre tres asteriscos. `espaciosBase` la alinea con el centro de la copa cuando esta tiene más de tres filas.
5. `require()` evita una altura cero o negativa, que no tendría sentido para el dibujo.

## Ejercicio 4.7 · Árbol de Navidad con `repeat`

> [!question] Enunciado
> Repite el ejercicio anterior, pero utiliza la función `repeat` en lugar de bucles `for` o `while`. Solicita la altura y dibuja las filas de la copa y la base de tres asteriscos.

### Clases y métodos introducidos
- `repeat(n) { indice -> ... }`: ejecuta el bloque `n` veces; el índice empieza en cero.
- `print()` / `println()`: imprimen caracteres y separan las filas.
- `require(condicion)`: valida la altura antes de empezar.

> **Términos explicados:** [[04 - Estructuras básicas#6. Bucles `for` y `repeat`|`repeat` e índice de iteración]] · [[04 - Estructuras básicas#8. Excepciones|validación con `require`]]

#### Ejemplo simple de funcionamiento
```kotlin
repeat(3) { indice ->
    print("${indice + 1} ")
}
// Imprime: 1 2 3
```

### Código fuente (`Ejercicio4.7/src/Main.kt`)

```kotlin
fun imprimirEspacios(cantidad: Int) {
    repeat(cantidad) { print(" ") }
}

fun imprimirAsteriscos(cantidad: Int) {
    repeat(cantidad) { print("*") }
}

fun main() {
    print("Altura del árbol: ")
    val altura = readln().toInt()

    repeat(altura - 1) { fila ->
        imprimirEspacios(altura - fila - 2)
        imprimirAsteriscos(fila * 2 + 1)
        println()
    }

    val espaciosBase = if (altura > 3) altura - 3 else 0
    imprimirEspacios(espaciosBase)
    imprimirAsteriscos(3)
    println()
}
```

### Explicación paso a paso
1. `repeat(altura - 1)` dibuja las filas de la copa y entrega el índice `fila`, que comienza en cero.
2. La fórmula `fila * 2 + 1` genera una cantidad impar y creciente de asteriscos.
3. `imprimirEspacios()` y `imprimirAsteriscos()` también usan `repeat`, sustituyendo todos los bucles del ejercicio anterior.
4. La base se dibuja después de la copa y siempre tiene tres asteriscos.
5. La validación garantiza que el número de repeticiones no sea negativo y que haya al menos una fila.

## Ejercicio 4.8 · Juego de adivinanza con `while`

> [!question] Enunciado
> Implementa un juego de adivinanza. Genera un número aleatorio entre 1 y 100 y pide al usuario que introduzca intentos hasta acertar. Después de cada intento incorrecto, indica si el número introducido es demasiado alto o demasiado bajo.
>
> Puedes generar el número con `java.util.Random.nextInt`.

### Clases y métodos introducidos
- `java.util.Random`: genera valores pseudoaleatorios.
- `Random.nextInt(limite)`: devuelve un entero desde 0 incluido hasta `limite` excluido.
- `while (condicion)`: repite el cuerpo mientras la condición sea verdadera.
- `readln().toInt()`: recibe y convierte cada intento del usuario.

> **Términos explicados:** [[04 - Estructuras básicas#7. Bucles while, break y continue|bucle `while`]] · [[02 - Jerarquia de tipos#4. Rangos y progresiones|rangos de valores]] · [[#Ejercicio 4.8 · Juego de adivinanza con `while`|generación pseudoaleatoria con `Random.nextInt`]]

#### Ejemplo simple de funcionamiento
```kotlin
var intentos = 0
while (intentos < 3) {
    println("Intento ${intentos + 1}")
    intentos++
}
```

### Código fuente (`Ejercicio4.8/src/Main.kt`)

```kotlin
import java.util.Random

fun main() {
    val numeroSecreto = Random().nextInt(100) + 1
    var intento = 0 // Fuera del rango posible; fuerza la primera iteración.

    while (intento != numeroSecreto) {
        print("Adivina el número (1–100): ")
        intento = readln().toInt()

        when {
            intento < numeroSecreto -> println("Demasiado bajo")
            intento > numeroSecreto -> println("Demasiado alto")
            else -> println("¡Correcto!")
        }
    }
}
```

### Explicación paso a paso
1. `Random().nextInt(100)` produce valores entre 0 y 99; al sumar 1, el secreto queda entre 1 y 100.
2. `intento` empieza en 0, fuera del rango del secreto; por eso el `while` entra al menos una vez.
3. Cada intento se lee como texto y se convierte a `Int`.
4. El `when` compara el intento con el secreto e informa si quedó por debajo, por encima o acertó.
5. El bucle termina cuando `intento == numeroSecreto`.

## Ejercicio 4.9 · Raíz cuadrada con `try-catch`

> [!question] Enunciado
> Escribe una función `calculateSquareRoot(number: Double): String` que devuelva un mensaje con la raíz cuadrada del número, con el formato **«La raíz cuadrada de _número_ es _resultado_»**.
>
> Si el número es negativo, lanza una excepción con el mensaje `"El número no puede ser negativo"`. Usa `try-catch` como expresión para gestionar esa excepción y construir el valor devuelto.

### Clases y métodos introducidos
- `kotlin.math.sqrt()`: calcula la raíz cuadrada de un valor `Double`.
- `IllegalArgumentException`: excepción adecuada cuando un argumento no cumple las condiciones esperadas.
- `try-catch` como expresión: devuelve el resultado del bloque `try` o del `catch` que gestione la excepción.
- `e.message`: obtiene el mensaje asociado a la excepción.

> **Términos explicados:** [[04 - Estructuras básicas#8. Excepciones|`try-catch`, `throw` y `IllegalArgumentException`]] · [[04 - Estructuras básicas#4. `when` como expresión|bloques como expresiones]] · [[#Ejercicio 4.9 · Raíz cuadrada con `try-catch`|función `sqrt`]]

#### Ejemplo simple de funcionamiento
```kotlin
val resultado = try {
    "Resultado: ${10 / 2}"
} catch (e: ArithmeticException) {
    "No se pudo calcular"
}
println(resultado)
```

### Código fuente (`Ejercicio4.9/src/Main.kt`)

```kotlin
import kotlin.math.sqrt

fun calculateSquareRoot(number: Double): String = try {
    if (number < 0.0) {
        throw IllegalArgumentException("El número no puede ser negativo")
    }
    "La raíz cuadrada de $number es ${sqrt(number)}"
} catch (e: IllegalArgumentException) {
    e.message ?: "No se pudo calcular la raíz cuadrada"
}

fun main() {
    println(calculateSquareRoot(25.0))
    println(calculateSquareRoot(-4.0))
}
```

### Explicación paso a paso
1. `sqrt` se importa desde `kotlin.math` y calcula el resultado para números no negativos.
2. Antes del cálculo, `number < 0.0` detecta el argumento inválido y lanza `IllegalArgumentException` con el mensaje pedido.
3. Como la llamada está dentro de `try`, la excepción se captura en el `catch` correspondiente.
4. La función devuelve el mensaje de la excepción; el operador Elvis `?:` proporciona un texto alternativo si el mensaje fuese nulo.
5. Al ser una expresión, `try-catch` devuelve directamente la cadena resultante en ambos caminos.

## Ejercicio 4.10 · Validación de edad con `try-catch`

> [!question] Enunciado
> Define `getValidAge(ageString: String): Int`. Usa una expresión `try-catch` para determinar el valor devuelto:
>
> - En `try`, convierte `ageString` a `Int` y usa `require()` para comprobar que la edad está entre 1 y 120, ambos incluidos. Proporciona un mensaje conciso si falla la validación.
> - Si ocurre `NumberFormatException` porque la cadena no representa un entero, devuelve `0`.
> - Si ocurre `IllegalArgumentException` porque falla `require()`, devuelve `-1`.
>
> En `main`, llama a `getValidAge` con `"25"`, `"abc"` y `"200"`, e imprime cada resultado. Coloca los bloques `catch` en un orden que permita capturar cada tipo correctamente.

### Clases y métodos introducidos
- `String.toInt()`: convierte una cadena a `Int`; si no representa un entero, lanza `NumberFormatException`.
- `require(condicion) { mensaje }`: valida un argumento y lanza `IllegalArgumentException` si la condición es falsa.
- `NumberFormatException` hereda de `IllegalArgumentException`; por eso su `catch` debe aparecer antes.
- `try-catch` como expresión: permite producir un entero distinto según el resultado o la excepción.

> **Términos explicados:** [[04 - Estructuras básicas#8. Excepciones|`try-catch`, `require` y jerarquía de excepciones]] · [[01 - Introduccion a Kotlin#6. Entrada desde consola|conversión con `String.toInt()`]] · [[02 - Jerarquia de tipos#4. Rangos y progresiones|validación con rangos]]

#### Ejemplo simple de funcionamiento
```kotlin
val cantidad = try {
    "12".toInt()
} catch (e: NumberFormatException) {
    0
}
println(cantidad) // 12
```

### Código fuente (`Ejercicio4.10/src/Main.kt`)

```kotlin
fun getValidAge(ageString: String): Int = try {
    val age = ageString.toInt()
    require(age in 1..120) { "La edad debe estar entre 1 y 120" }
    age
} catch (e: NumberFormatException) {
    0
} catch (e: IllegalArgumentException) {
    -1
}

fun main() {
    val inputs = listOf("25", "abc", "200")

    for (input in inputs) {
        println("$input → ${getValidAge(input)}")
    }
}
```

### Explicación paso a paso
1. `ageString.toInt()` convierte la entrada. Para `"abc"`, Kotlin lanza `NumberFormatException`.
2. Si la conversión funciona, `require(age in 1..120)` valida que la edad esté dentro del rango, incluidos ambos extremos.
3. Si las dos operaciones tienen éxito, la última expresión del `try`, `age`, es el valor devuelto.
4. `NumberFormatException` se captura primero y produce `0`. Aunque hereda de `IllegalArgumentException`, no llega al segundo bloque.
5. Si `require()` falla, se captura `IllegalArgumentException` y se devuelve `-1`. Así, las pruebas producen `25`, `0` y `-1`.
