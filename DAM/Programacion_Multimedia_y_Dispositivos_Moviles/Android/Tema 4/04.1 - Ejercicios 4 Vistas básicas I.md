## Ejercicio 4.1 · Proyecto CountingClicks

> [!question] Enunciado
> Realiza una aplicación que muestre cuántas veces se ha hecho click en un botón.
>
> En los apuntes del aula se acompaña de una animación del proyecto en ejecución: [abrir imagen](https://educacionadistancia.juntadeandalucia.es/centros/cadiz/pluginfile.php/244507/mod_resource/content/1/files/prCountingClicks.gif) (requiere iniciar sesión).

### Clases y métodos introducidos
- `Button` + `setOnClickListener { … }`: el *listener* de click escrito como lambda gracias a la conversión SAM.
- `TextView` con `android:textAppearance`: estilo tipográfico de Material para el contador.
- **Recurso de plural** (`<plurals>`) + `resources.getQuantityString(id, cantidad, args)`: «1 time» en singular y «0 times», «2 times»… en plural.
- Una propiedad `var times` de la actividad que guarda el estado (el número de clicks).

> **Términos explicados:** [[04 - Vistas básicas I#2. Button|`Button`]] · [[04 - Vistas básicas I#3. Listeners|*listeners* y lambdas]] · [[04 - Vistas básicas I#1. TextView|`TextView` y `textAppearance`]] · [[03 - Recursos#7. Recursos de plural|recursos de plural]] · [[10 - Programación funcional#6. Conversión SAM|conversión SAM]]

#### Ejemplo simple de funcionamiento
```kotlin
binding.btnClickMe.setOnClickListener {
    // Este bloque se ejecuta cada vez que el usuario pulsa el botón
    times++
}
```

### Código fuente (proyecto `CountingClicks`)

Proyecto *Empty Views Activity* con el paquete `es.iessaladillo.pedrojoya.countingclicks`, el *layout* renombrado a `main_activity.xml` y ViewBinding activado (`buildFeatures { viewBinding = true }` en `app/build.gradle.kts`, igual que en el [[03.1 - Ejercicios 3 Recursos|ejercicio 3.1]]).

#### `app/src/main/res/values/strings.xml`

```xml
<resources>
    <string name="app_name">CountingClicks</string>
    <string name="main_btnClickMe">Click me</string>

    <!-- Mismo plural que en los apuntes del Tema 3 -->
    <plurals name="main_times">
        <item quantity="one">%1$d time</item>
        <item quantity="other">%1$d times</item>
    </plurals>
</resources>
```

#### `app/src/main/res/values/dimens.xml`

```xml
<resources>
    <dimen name="main_padding">16dp</dimen>
    <dimen name="main_btnClickMe_marginTop">16dp</dimen>
</resources>
```

#### `app/src/main/res/layout/main_activity.xml`

```xml
<?xml version="1.0" encoding="utf-8"?>
<LinearLayout xmlns:android="http://schemas.android.com/apk/res/android"
    xmlns:tools="http://schemas.android.com/tools"
    android:id="@+id/llRoot"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:orientation="vertical"
    android:padding="@dimen/main_padding">

    <TextView
        android:id="@+id/lblTimes"
        android:layout_width="match_parent"
        android:layout_height="wrap_content"
        android:gravity="center"
        android:textAppearance="@style/TextAppearance.Material3.HeadlineSmall"
        tools:text="3 times" />

    <Button
        android:id="@+id/btnClickMe"
        android:layout_width="match_parent"
        android:layout_height="wrap_content"
        android:layout_marginTop="@dimen/main_btnClickMe_marginTop"
        android:text="@string/main_btnClickMe" />

</LinearLayout>
```

#### `app/src/main/java/es/iessaladillo/pedrojoya/countingclicks/MainActivity.kt`

```kotlin
package es.iessaladillo.pedrojoya.countingclicks

import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity
import es.iessaladillo.pedrojoya.countingclicks.databinding.MainActivityBinding

class MainActivity : AppCompatActivity() {

    private val binding: MainActivityBinding by lazy {
        MainActivityBinding.inflate(layoutInflater)
    }

    // Número de veces que se ha pulsado el botón
    private var times: Int = 0

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(binding.root)
        setupViews()
    }

    private fun setupViews() {
        binding.btnClickMe.setOnClickListener { incrementTimes() }
        // Muestra el valor inicial ("0 times") nada más arrancar
        showTimes()
    }

    private fun incrementTimes() {
        times++
        showTimes()
    }

    private fun showTimes() {
        // El primer times elige singular o plural; el segundo rellena el %1$d
        binding.lblTimes.text = resources.getQuantityString(R.plurals.main_times, times, times)
    }
}
```

### Explicación paso a paso
1. **Recursos.** Los textos van en `strings.xml` y las medidas en `dimens.xml`, como se practicó en el ejercicio 3.1. El contador usa el plural `main_times` de los apuntes, de modo que con 1 muestra «1 time» y con cualquier otro número «N times».
2. **El *layout*.** Es un `LinearLayout` vertical con dos hijos: el `TextView` del contador (`lblTimes`), centrado con `android:gravity="center"` y con estilo `HeadlineSmall`, y el `Button` (`btnClickMe`) debajo. `tools:text="3 times"` solo sirve para ver algo en el editor de diseño; en ejecución no aparece.
3. **El estado.** `times` es una propiedad `var` de la actividad. Vive mientras viva el objeto actividad y guarda cuántas veces se ha pulsado.
4. **`setupViews()`.** Asigna el *listener* del botón como lambda. Se puede porque `View.OnClickListener` es una interfaz de Java con un solo método abstracto (conversión SAM). Además llama a `showTimes()` para que el contador aparezca desde el principio con «0 times».
5. **`incrementTimes()` y `showTimes()`.** Cada click suma uno y repinta la etiqueta. Separar «cambiar el dato» de «mostrar el dato» deja una única función responsable de la interfaz: si mañana cambia el formato, se toca solo `showTimes()`.
6. **`getQuantityString()`.** No existe en `Activity`, así que se llama sobre `resources`. Recibe dos veces `times`: la primera para elegir entre `one` y `other`, y la segunda como argumento del `%1$d`.

> [!tip] Prueba
> Al arrancar se ve «0 times». Tras un click, «1 time» (singular); tras otro, «2 times». Si cambias el idioma del móvil no cambia nada, porque solo hay `values/` en inglés.

> [!warning] Si giras el móvil, el contador vuelve a 0
> Al girar la pantalla se produce un **cambio de configuración**: Android destruye la actividad y crea otra nueva, con `times = 0`. Es el comportamiento esperado con lo visto hasta ahora. Cómo conservar el estado se estudia más adelante, en los temas «Cambio de configuración» y «ViewModel».

## Esquema resumen de conceptos clave

| Concepto | Sintaxis | Uso en el ejercicio |
| --- | --- | --- |
| *Listener* de click | `btnClickMe.setOnClickListener { … }` | Reaccionar a cada pulsación. |
| Conversión SAM | lambda en lugar de `object : View.OnClickListener` | El *listener* ocupa una línea. |
| Estado en la actividad | `private var times: Int = 0` | Guarda el número de clicks. |
| Plural | `<plurals>` + `resources.getQuantityString(id, n, n)` | «1 time» / «N times» según la cantidad. |
| Estilo tipográfico | `android:textAppearance="@style/TextAppearance.Material3.HeadlineSmall"` | Contador grande, siguiendo Material Design. |
| Texto de diseño | `tools:text` | Vista previa en el editor sin afectar a la app. |
