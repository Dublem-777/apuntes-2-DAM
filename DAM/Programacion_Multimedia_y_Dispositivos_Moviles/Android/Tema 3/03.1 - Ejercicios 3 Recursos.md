## Ejercicio 3.1 · Proyecto HelloWorld con recursos

> [!question] Enunciado
> Modifica el proyecto HelloWorld que desarrollaste en un apartado anterior, para que haga uso de recursos de cadena y de dimensión.

### Clases y métodos introducidos
- **Recurso de cadena** (`<string>` en `res/values/strings.xml`): el texto deja de estar escrito a mano en el *layout* y en el código.
- **Recurso de dimensión** (`<dimen>` en `res/values/dimens.xml`): el margen y el tamaño de letra se nombran una vez y se reutilizan; `dp` para distancias y `sp` para texto.
- `@string/…` y `@dimen/…`: referencias a recursos desde el XML del *layout*.
- `setText(R.string.…)`: sobrecarga de `TextView` que recibe el `resId` de una cadena.

> **Términos explicados:** [[03 - Recursos#5. Recursos de cadena|recursos de cadena]] · [[03 - Recursos#10. Recursos de dimensión|recursos de dimensión, `dp` y `sp`]] · [[03 - Recursos#1. La clase Resources|`getString()` y `setText(resId)`]] · [[02 - Creación de un proyecto#14. ViewBinding|ViewBinding]]

#### Ejemplo simple de funcionamiento
```xml
<!-- res/values/dimens.xml -->
<dimen name="main_margin">16dp</dimen>

<!-- En el layout se usa con @dimen -->
android:layout_margin="@dimen/main_margin"
```

### Código fuente (proyecto `HelloWorld`)

Se parte del HelloWorld del Tema 2, con el *layout* ya renombrado a `main_activity.xml` y ViewBinding activado. Solo cambian los cuatro archivos siguientes.

#### `app/build.gradle.kts` (fragmento)

```kotlin
android {
    // ...
    buildFeatures {
        viewBinding = true
    }
}
```

#### `app/src/main/res/values/strings.xml`

```xml
<resources>
    <string name="app_name">HelloWorld</string>
    <!-- Texto inicial de la etiqueta (antes era el literal "Hello World!") -->
    <string name="main_lblMessage">Hello World!</string>
    <!-- Texto que pone la actividad al arrancar -->
    <string name="main_wonderful">Hello. What a wonderful world!</string>
</resources>
```

#### `app/src/main/res/values/dimens.xml`

```xml
<resources>
    <!-- Distancias en dp -->
    <dimen name="main_margin">16dp</dimen>
    <!-- Tamaños de texto en sp -->
    <dimen name="main_lblMessage_textSize">20sp</dimen>
</resources>
```

#### `app/src/main/res/layout/main_activity.xml`

```xml
<?xml version="1.0" encoding="utf-8"?>
<LinearLayout xmlns:android="http://schemas.android.com/apk/res/android"
    android:id="@+id/llRoot"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:orientation="vertical">

    <TextView
        android:id="@+id/lblMessage"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:layout_margin="@dimen/main_margin"
        android:text="@string/main_lblMessage"
        android:textSize="@dimen/main_lblMessage_textSize" />

</LinearLayout>
```

#### `app/src/main/java/es/iessaladillo/pedrojoya/helloworld/MainActivity.kt`

```kotlin
package es.iessaladillo.pedrojoya.helloworld

import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity
import es.iessaladillo.pedrojoya.helloworld.databinding.MainActivityBinding

class MainActivity : AppCompatActivity() {

    // El binding se infla la primera vez que se usa
    private val binding: MainActivityBinding by lazy {
        MainActivityBinding.inflate(layoutInflater)
    }

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(binding.root)
        setupViews()
    }

    private fun setupViews() {
        // El texto sale de un recurso de cadena, no de un literal
        binding.lblMessage.setText(R.string.main_wonderful)
    }
}
```

### Explicación paso a paso
1. **`strings.xml`.** Se crean dos recursos de cadena. Uno es el texto inicial del *layout* (`main_lblMessage`) y otro el que pone la actividad (`main_wonderful`). El prefijo `main_` indica a qué pantalla pertenecen, como en los apuntes.
2. **`dimens.xml`.** El margen de `16dp`, que antes estaba escrito en el *layout*, pasa a llamarse `main_margin`. Se añade también un tamaño de letra en `sp`. Así se ven las dos unidades del tema: `dp` para distancias y `sp` para texto, que respeta el tamaño de letra elegido en los ajustes del móvil.
3. **El *layout*.** Sustituye los literales por referencias: `@dimen/main_margin`, `@string/main_lblMessage` y `@dimen/main_lblMessage_textSize`. El *layout* ya no contiene ningún texto ni medida «a pelo».
4. **`MainActivity`.** Sigue el esquema de los apuntes: `binding` con `by lazy`, `setContentView(binding.root)` y la configuración de las vistas en `setupViews()`.
5. **`setText(R.string.main_wonderful)`.** Se llama al **método** `setText()` con el `resId`, que busca la cadena por nosotros. No vale `binding.lblMessage.text = R.string.main_wonderful`: en Kotlin la propiedad `text` es `CharSequence` y no admite un `Int`. La alternativa equivalente es `binding.lblMessage.text = getString(R.string.main_wonderful)`.

> [!tip] Prueba
> Al ejecutar la app debe aparecer «Hello. What a wonderful world!» con un margen de 16 dp y letra de 20 sp. Para comprobar que todo sale de los recursos, cambia el valor de `main_margin` en `dimens.xml` o el texto de `main_wonderful`: la app cambia sin tocar ni el *layout* ni el código.

> [!example] ¿Para qué sirve esto?
> Si mañana quieres la app en español, basta con crear `res/values-es/strings.xml` con las mismas claves traducidas. El código y el *layout* no cambian: Android elige el archivo según el idioma del móvil. Por eso los apuntes recomiendan usar siempre recursos en lugar de literales.

## Esquema resumen de conceptos clave

| Concepto | Sintaxis | Uso en el ejercicio |
| --- | --- | --- |
| Recurso de cadena | `<string name="main_wonderful">…</string>` | Textos de la etiqueta, fuera del código. |
| Recurso de dimensión | `<dimen name="main_margin">16dp</dimen>` | Margen (`dp`) y tamaño de letra (`sp`) con nombre. |
| Referencia desde XML | `@string/x` · `@dimen/x` | Los atributos del `TextView` apuntan a los recursos. |
| Referencia desde código | `setText(R.string.x)` · `getString(R.string.x)` | La actividad pone el texto usando su `resId`. |
| ViewBinding | `MainActivityBinding.inflate(layoutInflater)` | Acceso a `lblMessage` sin `findViewById()`. |
