## Ejercicio 5.1 · Smart cast con `if`

> [!question] Enunciado
> Define `getNameLength`, que reciba un parámetro inmutable `userName` de tipo `String?` y devuelva un `Int`. Usa una expresión `if/else`: si `userName` no es `null`, devuelve su longitud sin usar `?.` ni `!!`; si es `null`, devuelve `0`. En `main`, llama a la función con `"Developer"` y con `null`, e imprime ambos resultados.

### Clases y métodos introducidos
- `String?`: cadena nullable, que puede contener texto o `null`.
- Smart cast: tras comprobar `userName != null`, el compilador permite acceder a `userName.length` como `String`.
- `if/else` como expresión: cada rama produce el valor devuelto por la función.

> **Términos explicados:** [[05 - Operaciones con tipos nullables#1. Smart cast hacia tipos no nullables|smart cast y tipos nullable]] · [[04 - Estructuras básicas#4. `when` como expresión|`if` como expresión]]

#### Ejemplo simple de funcionamiento
```kotlin
val texto: String? = "Kotlin"
val longitud = if (texto != null) texto.length else 0
println(longitud) // 6
```

### Código fuente (`Ejercicio5.1/src/Main.kt`)

```kotlin
fun getNameLength(userName: String?): Int =
    if (userName != null) userName.length else 0

fun main() {
    println(getNameLength("Developer"))
    println(getNameLength(null))
}
```

### Explicación paso a paso
1. La firma acepta una cadena o `null`, pero promete devolver siempre un `Int` no nullable.
2. La condición `userName != null` demuestra que la cadena existe en la primera rama.
3. El smart cast permite usar `.length` directamente, sin `?.` ni `!!`.
4. La segunda rama proporciona `0`; los resultados de las llamadas son `9` y `0`.

## Ejercicio 5.2 · Llamadas seguras encadenadas

> [!question] Enunciado
> Crea una clase `Person` con una propiedad `name` de tipo `String?`. Escribe `getNameLength`, que reciba `Person?` y devuelva la longitud del nombre si el objeto y su nombre existen; en caso contrario, devuelve `0`. Resuelve el acceso usando llamadas seguras. Prueba los casos con nombre, nombre nulo y persona nula.

### Clases y métodos introducidos
- Propiedad nullable: `name: String?` admite la ausencia del nombre.
- Llamadas seguras encadenadas: `person?.name?.length` detiene el acceso si cualquier eslabón es `null`.
- Elvis `?:`: convierte el resultado nullable en una longitud con valor predeterminado `0`.

> **Términos explicados:** [[05 - Operaciones con tipos nullables#2. Operador de llamada segura `?.`|llamadas seguras encadenadas]] · [[05 - Operaciones con tipos nullables#3. Operador Elvis `?:`|operador Elvis]]

#### Ejemplo simple de funcionamiento
```kotlin
val longitud = texto?.length ?: 0
```

### Código fuente (`Ejercicio5.2/src/Main.kt`)

```kotlin
class Person(val name: String?)

fun getNameLength(person: Person?): Int =
    person?.name?.length ?: 0

fun main() {
    println(getNameLength(Person("Ada")))
    println(getNameLength(Person(null)))
    println(getNameLength(null))
}
```

### Explicación paso a paso
1. `person?.name` produce `null` si `person` no existe; si existe, obtiene la propiedad nullable `name`.
2. `?.length` solo lee la longitud cuando el nombre tampoco es `null`.
3. Toda la cadena tiene tipo `Int?`; Elvis devuelve `0` cuando el resultado es `null`.
4. Las tres llamadas imprimen `3`, `0` y `0`.

## Ejercicio 5.3 · Acceso seguro a un mapa

> [!question] Enunciado
> Define `getConfigValue`, que reciba `configMap: Map<String, String>?` y `key: String`, y devuelva `String?`. En una sola línea, usa `?.` para acceder al valor asociado a la clave si el mapa existe. En `main`, prueba un mapa con `"Timeout"` asociado a `"5000"` y un mapa nulo; imprime ambos resultados.

### Clases y métodos introducidos
- `Map<String, String>`: mapa de claves y valores de tipo `String`.
- `Map.get(key)`: obtiene el valor o `null` si la clave no existe.
- `configMap?.get(key)`: evita acceder al mapa cuando este es `null`; el resultado es `String?`.

> **Términos explicados:** [[02 - Jerarquia de tipos#10. Arrays|colecciones y mapas]] · [[05 - Operaciones con tipos nullables#2. Operador de llamada segura `?.`|llamada segura `?.`]]

#### Ejemplo simple de funcionamiento
```kotlin
val valor: String? = mapa?.get("Timeout")
```

### Código fuente (`Ejercicio5.3/src/Main.kt`)

```kotlin
fun getConfigValue(
    configMap: Map<String, String>?,
    key: String,
): String? = configMap?.get(key)

fun main() {
    val settings: Map<String, String>? = mapOf("Timeout" to "5000")
    val nullSettings: Map<String, String>? = null

    println(getConfigValue(settings, "Timeout"))
    println(getConfigValue(nullSettings, "Timeout"))
}
```

### Explicación paso a paso
1. `configMap?.get(key)` ejecuta `get` solo si el mapa no es `null`.
2. El resultado sigue siendo nullable: puede faltar el mapa o no existir la clave solicitada.
3. La primera llamada imprime `5000`; la segunda imprime `null`.

## Ejercicio 5.4 · Nombre alternativo con Elvis

> [!question] Enunciado
> Escribe `formatName`, con parámetros `firstName: String`, `lastName: String?` y `nickname: String?`. Devuelve el apodo si se proporciona; si no, devuelve nombre y apellido cuando exista apellido; si tampoco hay apellido, devuelve solo el nombre. Usa el operador Elvis para resolver los valores nullable.

### Clases y métodos introducidos
- `?:`: selecciona la expresión de la izquierda si no es `null`; si lo es, evalúa la de la derecha.
- `let`: ejecuta una transformación con el valor no nulo y devuelve el resultado del bloque.
- Una cadena vacía no equivale a `null`: el operador Elvis solo utiliza el valor alternativo ante `null`.

> **Términos explicados:** [[05 - Operaciones con tipos nullables#3. Operador Elvis `?:`|operador Elvis]] · [[05 - Operaciones con tipos nullables#2. Operador de llamada segura `?.`|llamada segura y `let`]]

#### Ejemplo simple de funcionamiento
```kotlin
val etiqueta = apodo ?: nombre
```

### Código fuente (`Ejercicio5.4/src/Main.kt`)

```kotlin
fun formatName(
    firstName: String,
    lastName: String?,
    nickname: String?,
): String =
    nickname ?: (lastName?.let { "$firstName $it" } ?: firstName)

fun main() {
    println(formatName("Ada", "Lovelace", "Enchantress"))
    println(formatName("Ada", "Lovelace", null))
    println(formatName("Ada", null, null))
}
```

### Explicación paso a paso
1. El primer Elvis devuelve `nickname` directamente si existe.
2. Si no hay apodo, `lastName?.let { ... }` construye el nombre completo solo cuando hay apellido.
3. El segundo Elvis usa `firstName` cuando `lastName` es `null`.
4. Las llamadas imprimen `Enchantress`, `Ada Lovelace` y `Ada`.

## Ejercicio 5.5 · Valor predeterminado y excepción con Elvis

> [!question] Enunciado
> Define `getProcessedId(userMap: Map<String, String>?)`, que devuelva el valor asociado a `"UserID"` o `"ID-UNKNOWN"` si no se puede obtener. Define también `getRequiredId`, que obtenga `"RequiredID"` o lance `IllegalStateException` con el mensaje `"The required ID is missing"`. Usa `?.` y Elvis en ambas funciones. En `main`, prueba mapas con valores, un mapa sin la clave y un mapa nulo; gestiona con `try-catch` la excepción de `getRequiredId`.

### Clases y métodos introducidos
- `Map<String, String>?`: tanto el mapa como el resultado de `get` pueden ser nulos.
- Llamada segura + Elvis: `mapa?.get(clave) ?: valorPredeterminado` gestiona ambas causas de ausencia.
- `throw` a la derecha de Elvis: permite lanzar una excepción cuando falta un dato obligatorio.
- `IllegalStateException`: indica que no se puede completar la operación por el estado actual.

> **Términos explicados:** [[05 - Operaciones con tipos nullables#2. Operador de llamada segura `?.`|llamada segura `?.`]] · [[05 - Operaciones con tipos nullables#3. Operador Elvis `?:`|Elvis con valor alternativo o excepción]] · [[04 - Estructuras básicas#8. Excepciones|`IllegalStateException` y `try-catch`]]

#### Ejemplo simple de funcionamiento
```kotlin
val codigo = datos?.get("id") ?: "desconocido"
```

### Código fuente (`Ejercicio5.5/src/Main.kt`)

```kotlin
fun getProcessedId(userMap: Map<String, String>?): String =
    userMap?.get("UserID") ?: "ID-UNKNOWN"

fun getRequiredId(userMap: Map<String, String>?): String =
    userMap?.get("RequiredID") ?: throw IllegalStateException("The required ID is missing")

fun main() {
    println(getProcessedId(mapOf("UserID" to "A123")))
    println(getProcessedId(null))

    println(getRequiredId(mapOf("RequiredID" to "B456")))

    try {
        println(getRequiredId(mapOf("OtherKey" to "Value")))
    } catch (e: IllegalStateException) {
        println("Error: ${e.message}")
    }

    try {
        println(getRequiredId(null))
    } catch (e: IllegalStateException) {
        println("Error: ${e.message}")
    }
}
```

### Explicación paso a paso
1. En `getProcessedId`, `?.get("UserID")` produce `null` si el mapa falta o no tiene esa clave; Elvis devuelve `"ID-UNKNOWN"`.
2. `getRequiredId` usa la misma consulta, pero la rama alternativa lanza la excepción requerida.
3. Un mapa sin `"RequiredID"` y un mapa nulo provocan el mismo caso: no hay un valor obligatorio que devolver.
4. El `try-catch` captura `IllegalStateException` y permite que el programa continúe. El mapa con `"RequiredID"` imprime `B456`.

## Ejercicio 5.6 · Aserción no nula con `!!`

> [!question] Enunciado
> Define `processItem(dataString: String?)`. Calcula y guarda la longitud en una variable inmutable llamada `finalLength`, usando `!!` para acceder a `length`, e imprime el resultado. En `main`, llama a la función con `"TestValue"` y con `null`. Explica qué sucede en la segunda llamada y por qué se desaconseja esta práctica.

### Clases y métodos introducidos
- `!!`: fuerza una expresión nullable a su tipo no nullable.
- `NullPointerException`: excepción lanzada por `!!` si el valor es `null`.
- `try-catch`: permite mostrar el fallo sin detener el resto del ejemplo.

> **Términos explicados:** [[05 - Operaciones con tipos nullables#4. Operador de aserción no nula `!!`|aserción no nula y `NullPointerException`]] · [[04 - Estructuras básicas#8. Excepciones|captura con `try-catch`]]

#### Ejemplo simple de funcionamiento
```kotlin
val longitud = texto!!.length // Falla si texto es null
```

### Código fuente (`Ejercicio5.6/src/Main.kt`)

```kotlin
fun processItem(dataString: String?) {
    val finalLength = dataString!!.length
    println("Longitud: $finalLength")
}

fun main() {
    processItem("TestValue")

    try {
        processItem(null)
    } catch (e: NullPointerException) {
        println("No se pudo procesar null: ${e.javaClass.simpleName}")
    }
}
```

### Explicación paso a paso
1. Con `"TestValue"`, `!!` obtiene la cadena no nullable y `length` devuelve `9`.
2. Con `null`, `!!` lanza `NullPointerException` antes de que se asigne `finalLength`.
3. El `catch` muestra la excepción y permite que `main` termine normalmente.
4. Se desaconseja `!!` porque convierte una ausencia de datos en un fallo de ejecución y no ofrece un mensaje de dominio claro. Una comprobación, `?:` o `requireNotNull()` suele expresar mejor el comportamiento esperado.

## Ejercicio 5.7 · Cast seguro con `as?`

> [!question] Enunciado
> Escribe `sumIfAllIntegers`, que acepte una cantidad variable de argumentos de tipo `Any` mediante `vararg`. Convierte cada argumento a `Int` con `as?`. Si todos son enteros, devuelve su suma; si alguno no se puede convertir, devuelve `null`. Prueba ambos resultados en `main`.

### Clases y métodos introducidos
- `vararg values: Any`: acepta una cantidad variable de argumentos; dentro de la función se recorren como una colección de valores.
- `as? Int`: devuelve el valor convertido o `null` si el objeto no es un `Int`.
- Elvis con `return null`: termina la función en cuanto una conversión falla.
- `Int?`: permite devolver una suma o `null` para indicar que no se pudieron convertir todos los valores.

> **Términos explicados:** [[05 - Operaciones con tipos nullables#5. Operadores de cast `as` y `as?`|cast seguro `as?`]] · [[03 - Funciones#9. varargs|parámetros `vararg`]] · [[05 - Operaciones con tipos nullables#3. Operador Elvis `?:`|Elvis y retorno anticipado]]

#### Ejemplo simple de funcionamiento
```kotlin
val entero: Int? = valor as? Int
```

### Código fuente (`Ejercicio5.7/src/Main.kt`)

```kotlin
fun sumIfAllIntegers(vararg values: Any): Int? {
    var sum = 0

    for (value in values) {
        val integer = value as? Int ?: return null
        sum += integer
    }

    return sum
}

fun main() {
    println(sumIfAllIntegers(1, 2, 3, 4))
    println(sumIfAllIntegers(1, 2, "3", 4))
}
```

### Explicación paso a paso
1. Cada argumento se procesa como `Any`; el cast seguro comprueba su tipo real en tiempo de ejecución.
2. Si un valor no es un `Int`, `as?` produce `null` y Elvis ejecuta `return null` inmediatamente.
3. Si todas las conversiones funcionan, se acumulan los enteros y se devuelve la suma.
4. Las llamadas imprimen `10` y `null`. Un valor `Double` como `3.0` tampoco es un `Int`, aunque represente un número sin parte decimal.
