
# 1. ¿Qué problemas detectáis y a quién perjudican?

El inventario se controla con varias hojas de cálculo - afecta a ventas

los pedidos llegan por correo electrónico - afecta a almacén

las facturas se preparan en un programa independiente - contabilidad

los datos de clientes se guardan en distintos archivos - ventas y atencion al cliente

#  2. ¿Qué información necesita vuestro departamento?

información de las facturas, los datos del cliente.

# 3. ¿De quién debe recibirla y a quién debe comunicarla?

recibirlas de venta y se comunican a dirección.

# 4. ¿Qué ocurre si los datos llegan tarde o son incorrectos?

abría desfase entre departamentos, y atención al cliente no tendría la información del cliente.

el cliente podría recibir una factura con datos incorrectos con compras que no haya hecho.

# 5. ¿Qué debería resolver un sistema de gestión integrado?

La comunicación entre departamentos y la unificación en una herramienta común para todos los departamentos.

La gestión de datos entre clientes frente a la información de la empresa.

Saber los stocks de almacén a tiempo real.

La relación entre el cliente con la empresa a través de atención al cliente y la sincronización entre los departamentos.
