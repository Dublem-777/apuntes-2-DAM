# Exercises

## 1. Complete the sentences
1. If you use a **spreadsheet**, it will be easier to plan the budget  
2. If we use online **tools**, it will be easier to work together on this project. 
3. If we list the customer orders in a **table**, we'll see all the dates and prices better. 
4. The customer will be happier if we **customise** the software. 
5. It will be quicker if we **sort** the emails by date or sender. 
6. If I **configure** the software, it will work with our database. 
7. If we **track** our progress, it will be easier to see what is finished. 
8. It will be much clearer if we **filter** the emails from this week.
