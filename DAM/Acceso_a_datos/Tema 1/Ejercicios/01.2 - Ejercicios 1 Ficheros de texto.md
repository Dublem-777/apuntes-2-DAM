## Ejercicio 1: Copiar y concatenar ficheros de texto

> [!question] Enunciado
> Crea un método con tres parámetros: `Path source`, `Path destination` y `boolean appended`.
>
> - Si el destino es un directorio:
>   - Si el origen también es un directorio, lanza `IllegalArgumentException`.
>   - Si el origen es un fichero, crea en el directorio destino una copia del fichero origen usando `Files.copy`. Muestra por consola el contenido del fichero destino.
> - Si el destino es un fichero:
>   - Si el origen es un directorio, lanza `IllegalArgumentException`.
>   - Si el origen es un fichero y el destino no existe, créalo y copia el contenido usando `Files.writeString`. Muestra el fichero destino.
>   - Si el destino existe y `appended` es `false`, sobrescribe su contenido usando `Files.write`. Muestra el fichero destino.
>   - Si el destino existe y `appended` es `true`, conserva su contenido y añade el del origen. Muestra el fichero destino.

### Clases y métodos introducidos

- `Files.isDirectory`: distingue directorios de ficheros.
- `Files.copy`: copia el fichero origen a una ruta destino.
- `Files.readString`, `Files.writeString` y `Files.write`: permiten leer, reemplazar y añadir contenido.
- `StandardOpenOption.APPEND`: conserva el contenido existente y escribe al final.

> **Términos explicados:** [[01 - Ficheros#3. La clase Files|`Files.copy` y operaciones con ficheros]] · [[01 - Ficheros#7.2 Método Files.writeString|escritura, sobrescritura y opción `APPEND`]] · [[01 - Ficheros#7.3 Método Files.write|`Files.write`]]

#### Ejemplo simple de funcionamiento
```java
Path source = Paths.get("origen.txt");
Path destination = Paths.get("destino.txt");
String content = Files.readString(source, StandardCharsets.UTF_8);
Files.writeString(destination, content, StandardCharsets.UTF_8,
        StandardOpenOption.APPEND);
```

### Conceptos clave

- `Files.isDirectory(path)`: distingue directorios de ficheros.
- `destination.resolve(source.getFileName())`: crea dentro del directorio destino una ruta con el nombre del fichero origen.
- `Files.copy(source, target)`: copia un fichero y, por defecto, falla si el destino ya existe.
- `Files.readString` y `Files.writeString`: leen y escriben el contenido de texto completo.
- `Files.write`: escribe una lista de líneas; sin opciones adicionales, crea el destino o reemplaza su contenido.
- `StandardOpenOption.APPEND`: añade texto al final de un fichero existente.

### Código (`Ejercicio1.java`)

```java
package ejercicios1_FicherosTexto;

import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;
import java.nio.file.StandardOpenOption;
import java.util.List;

public class Ejercicio1 {

    public void copiar(Path source, Path destination, boolean appended) throws IOException {
        // Un origen que sea directorio no se admite en ninguno de los dos casos.
        if (Files.isDirectory(source)) {
            throw new IllegalArgumentException("El origen debe ser un fichero: " + source);
        }

        if (Files.isDirectory(destination)) {
            // Si el destino es una carpeta, la copia conserva el nombre del origen.
            Path target = destination.resolve(source.getFileName());
            Files.copy(source, target);
            mostrarContenido(target);
            return;
        }

        if (!Files.exists(destination)) {
            // Primera escritura: crea el fichero y copia el texto completo.
            String content = Files.readString(source, StandardCharsets.UTF_8);
            Files.writeString(destination, content, StandardCharsets.UTF_8);
        } else if (appended) {
            // APPEND conserva el contenido existente y agrega el contenido de origen.
            String content = Files.readString(source, StandardCharsets.UTF_8);
            Files.writeString(destination, content, StandardCharsets.UTF_8,
                    StandardOpenOption.APPEND);
        } else {
            // readAllLines + write reemplaza el contenido del destino.
            List<String> lines = Files.readAllLines(source, StandardCharsets.UTF_8);
            Files.write(destination, lines, StandardCharsets.UTF_8);
        }

        mostrarContenido(destination);
    }

    private void mostrarContenido(Path file) throws IOException {
        System.out.println("Contenido de " + file + ":");
        System.out.print(Files.readString(file, StandardCharsets.UTF_8));
        System.out.println();
    }

    public static void main(String[] args) {
        Path source = Paths.get("files", "origen.txt");
        Path destination = Paths.get("files", "destino.txt");

        try {
            new Ejercicio1().copiar(source, destination, true);
        } catch (IOException e) {
            System.err.printf("Error al copiar el fichero: %s%n", e.getMessage());
        }
    }
}
```

### Explicación paso a paso

1. **Validar el origen:** si `Files.isDirectory(source)` es `true`, se lanza la excepción solicitada. Si no existe, la operación posterior informará del error mediante `IOException`.
2. **Detectar el destino directorio:** se compone `target` con `resolve` y se copia el archivo. `Files.copy` no sobrescribe una copia anterior; si ya existe, comunica el error.
3. **Crear un destino que aún no existe:** se lee el origen como texto UTF-8 y se escribe con `Files.writeString`.
4. **Elegir entre reemplazar o añadir:** para reemplazar se utiliza `Files.write`; para añadir se especifica `StandardOpenOption.APPEND`.
5. **Mostrar el resultado:** `mostrarContenido` lee el destino después de la operación y lo imprime.

> [!tip] Prueba
> Crea `files/origen.txt` con varias líneas y ejecuta el programa varias veces. Cambia el tercer argumento a `false` para probar la sobrescritura; con `true`, cada ejecución añade otra copia del texto.

## Ejercicio 2: Cifrar y descifrar un fichero

> [!question] Enunciado
> Realiza un programa para cifrar y descifrar los datos de un fichero de texto. Se introduce una cadena por teclado que será la clave. A cada carácter del fichero se le suma el valor Unicode de un carácter de la clave; al terminar la clave, se vuelve a su primer carácter. Los datos cifrados se escriben en un fichero destino, que se puede utilizar como origen para descifrar aplicando la operación inversa.
>
> Por ejemplo, para el texto `abcdef` y la clave `rosa`, el resultado es `ÓÑÖÅ×Õ`: se suma `r` a `a`, `o` a `b`, `s` a `c`, `a` a `d`, y se vuelve a empezar por `r`.

### Clases y métodos introducidos

- `Files.readString` y `Files.writeString`: leen y escriben texto usando una codificación explícita.
- `String.toCharArray`: convierte el contenido en un array modificable de caracteres.
- `String.charAt` y el operador `%`: seleccionan cíclicamente los caracteres de la clave.
- `Scanner`: recoge la clave, el modo y las rutas desde consola.

> **Términos explicados:** [[#Ejercicio 2: Cifrar y descifrar un fichero|cifrado por desplazamiento y clave cíclica]] · [[01 - Ficheros#7. Ficheros de texto|lectura y escritura de ficheros de texto]] · [[01 - Ficheros#7.1 Método Files.readAllLines|codificación de texto UTF-8]]

#### Ejemplo simple de funcionamiento
```java
String text = "abc";
String key = "xy";
char[] result = text.toCharArray();
for (int i = 0; i < result.length; i++) {
    result[i] = (char) (result[i] + key.charAt(i % key.length()));
}
System.out.println(new String(result));
```

### Conceptos clave

- `String.toCharArray()`: permite procesar el contenido carácter a carácter.
- `i % key.length()`: repite cíclicamente los caracteres de la clave.
- Para descifrar se resta el valor de la clave en vez de sumarlo.
- El cifrado de este ejercicio es didáctico; no es un método seguro para proteger información real.

### Código (`Ejercicio2.java`)

```java
package ejercicios1_FicherosTexto;

import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;
import java.util.Scanner;

public class Ejercicio2 {

    private void transformar(Path source, Path destination, String key, boolean decrypt)
            throws IOException {
        if (key.isEmpty()) {
            throw new IllegalArgumentException("La clave no puede estar vacía.");
        }

        char[] data = Files.readString(source, StandardCharsets.UTF_8).toCharArray();

        for (int i = 0; i < data.length; i++) {
            // El módulo hace que la clave vuelva a empezar al llegar a su final.
            int keyCharacter = key.charAt(i % key.length());
            int result = decrypt ? data[i] - keyCharacter : data[i] + keyCharacter;
            data[i] = (char) result;
        }

        Files.writeString(destination, new String(data), StandardCharsets.UTF_8);
    }

    public void show() {
        try (Scanner scanner = new Scanner(System.in)) {
            System.out.print("Introduce la clave: ");
            String key = scanner.nextLine();

            System.out.print("¿Cifrar o descifrar? (c/d): ");
            boolean decrypt = scanner.nextLine().trim().equalsIgnoreCase("d");

            System.out.print("Ruta del fichero origen: ");
            Path source = Paths.get(scanner.nextLine().trim());
            System.out.print("Ruta del fichero destino: ");
            Path destination = Paths.get(scanner.nextLine().trim());

            transformar(source, destination, key, decrypt);
            System.out.println("Operación terminada. Resultado guardado en: " + destination);
        } catch (IOException e) {
            System.err.printf("Error al procesar el fichero: %s%n", e.getMessage());
        }
    }

    public static void main(String[] args) {
        new Ejercicio2().show();
    }
}
```

### Explicación paso a paso

1. **Leer las entradas:** se solicitan la clave, la operación y las rutas de origen y destino.
2. **Validar la clave:** una clave vacía no se puede repetir cíclicamente, por eso se rechaza antes de procesar el texto.
3. **Leer el fichero:** `Files.readString` carga el texto en memoria y `toCharArray()` lo convierte en un array modificable.
4. **Transformar cada carácter:** `i % key.length()` selecciona el carácter de clave correspondiente. Se suma para cifrar y se resta para descifrar.
5. **Guardar:** el array transformado vuelve a convertirse en `String` y se escribe con UTF-8.

> [!tip] Comprobación
> Cifra un fichero y luego ejecuta el programa otra vez seleccionando `d`; usa como origen el fichero cifrado y como destino otro fichero. El resultado debe coincidir con el texto inicial.

## Ejercicio 3: Analizar recursos y excepciones del boletín

> [!question] Enunciado
> Utiliza `BufferedReader` y `BufferedWriter` para concatenar todos los ficheros `.java` de este boletín en uno. Lee el fichero resultante y genera dos ficheros:
>
> 1. Las declaraciones realizadas en los paréntesis de cada `try-with-resources`, una por línea y terminada en `;`. Por ejemplo: `Stream<Path> directoryContents;`, `BufferedReader reader;`, `BufferedWriter writer;`.
> 2. Las declaraciones de las excepciones de los bloques `catch`, una por línea, terminadas en `;` y sin repetir tipos. Por ejemplo: `FileNotFoundException e;`, `IOException e;`, `FileAlreadyExistsException e;`, `NoSuchFileException e;`, `NotDirectoryException e;`.

### Clases y métodos introducidos

- `Files.list` y `Files.isRegularFile`: localizan ficheros fuente del boletín.
- `BufferedReader` y `BufferedWriter`: procesan y concatenan texto de forma secuencial.
- `Pattern` y `Matcher`: localizan estructuras `try` y `catch` en el código.
- `LinkedHashMap`: elimina tipos de excepción duplicados y conserva el orden.

> **Términos explicados:** [[01 - Ficheros#5.1 try-with-resources|`try-with-resources` y declaración de recursos]] · [[01 - Ficheros#1.3 Excepciones|excepciones y captura con `catch`]] · [[#Ejercicio 3: Analizar recursos y excepciones del boletín|expresiones regulares para analizar código]]

#### Ejemplo simple de funcionamiento
```java
try (BufferedReader reader = Files.newBufferedReader(source, StandardCharsets.UTF_8);
     BufferedWriter writer = Files.newBufferedWriter(destination, StandardCharsets.UTF_8)) {
    String line;
    while ((line = reader.readLine()) != null) {
        writer.write(line);
        writer.newLine();
    }
}
```

### Conceptos clave

- `Files.list`: obtiene los ficheros del paquete; se filtra por extensión `.java`.
- `BufferedReader` y `BufferedWriter`: permiten leer y escribir texto de forma secuencial.
- `try-with-resources`: cierra automáticamente los flujos al terminar.
- Una expresión regular localiza los bloques `catch`; el recorrido de paréntesis identifica los recursos aunque sus inicializadores contengan llamadas a métodos.
- `LinkedHashMap`: elimina excepciones repetidas y conserva el orden de aparición.

### Código (`Ejercicio3.java`)

```java
package ejercicios1_FicherosTexto;

import java.io.BufferedReader;
import java.io.BufferedWriter;
import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;
import java.util.ArrayList;
import java.util.Comparator;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;
import java.util.regex.Matcher;
import java.util.regex.Pattern;
import java.util.stream.Collectors;
import java.util.stream.Stream;

public class Ejercicio3 {

    public void show() throws IOException {
        Path sourceDirectory = Paths.get("src", "ejercicios1_FicherosTexto");
        Path outputDirectory = Paths.get("files");
        Files.createDirectories(outputDirectory);

        Path combinedFile = outputDirectory.resolve("boletin_completo.txt");
        Path resourcesFile = outputDirectory.resolve("recursos_try.txt");
        Path exceptionsFile = outputDirectory.resolve("excepciones_catch.txt");

        // Truncar el resultado anterior evita duplicar contenido en cada ejecución.
        // El orden alfabético hace que el fichero combinado sea reproducible.
        List<Path> sources;
        try (Stream<Path> javaFiles = Files.list(sourceDirectory)) {
            sources = javaFiles
                    .filter(Files::isRegularFile)
                    .filter(path -> path.getFileName().toString().endsWith(".java"))
                    .sorted(Comparator.comparing(path -> path.getFileName().toString()))
                    .collect(Collectors.toList());
        }

        // newBufferedWriter crea el resultado o trunca el anterior en cada ejecución.
        try (BufferedWriter writer = Files.newBufferedWriter(combinedFile, StandardCharsets.UTF_8)) {
            for (Path source : sources) {
                writer.write("// ===== " + source.getFileName() + " =====");
                writer.newLine();

                // BufferedReader lee cada fuente y BufferedWriter concatena sus líneas.
                try (BufferedReader reader = Files.newBufferedReader(source, StandardCharsets.UTF_8)) {
                    String line;
                    while ((line = reader.readLine()) != null) {
                        writer.write(line);
                        writer.newLine();
                    }
                }
            }
        }

        // Leer de nuevo el fichero combinado, como pide el enunciado, para analizarlo.
        StringBuilder combined = new StringBuilder();
        try (BufferedReader reader = Files.newBufferedReader(combinedFile, StandardCharsets.UTF_8)) {
            String line;
            while ((line = reader.readLine()) != null) {
                combined.append(line).append('\n');
            }
        }

        List<String> resourceDeclarations = extractResources(combined.toString());
        List<String> exceptionDeclarations = extractExceptions(combined.toString());

        Files.write(resourcesFile, resourceDeclarations, StandardCharsets.UTF_8);
        Files.write(exceptionsFile, exceptionDeclarations, StandardCharsets.UTF_8);

        System.out.println("Fichero combinado: " + combinedFile);
        System.out.println("Recursos encontrados: " + resourcesFile);
        System.out.println("Excepciones encontradas: " + exceptionsFile);
    }

    private List<String> extractResources(String source) {
        String code = maskCommentsAndLiterals(source);
        Matcher matcher = Pattern.compile("\\btry\\s*\\(").matcher(code);
        List<String> declarations = new ArrayList<>();

        while (matcher.find()) {
            int open = code.indexOf('(', matcher.start());
            int depth = 1;
            int segmentStart = open + 1;
            int end = code.length();

            // Se cuentan los paréntesis anidados de las llamadas en los inicializadores.
            for (int i = open + 1; i < code.length() && depth > 0; i++) {
                char current = code.charAt(i);
                if (current == '(') {
                    depth++;
                } else if (current == ')') {
                    if (depth == 1) {
                        addResourceDeclaration(source.substring(segmentStart, i), declarations);
                        end = i + 1;
                    }
                    depth--;
                } else if (current == ';' && depth == 1) {
                    addResourceDeclaration(source.substring(segmentStart, i), declarations);
                    segmentStart = i + 1;
                }
            }

            // Continuar después del paréntesis evita analizar texto del mismo encabezado.
            matcher.region(end, code.length());
        }

        return declarations;
    }

    private void addResourceDeclaration(String resource, List<String> declarations) {
        String declaration = resource.trim();
        if (declaration.isEmpty()) {
            return;
        }

        // El enunciado pide declaraciones, no sus expresiones de inicialización.
        int depth = 0;
        for (int i = 0; i < declaration.length(); i++) {
            char current = declaration.charAt(i);
            if (current == '(' || current == '[') {
                depth++;
            } else if (current == ')' || current == ']') {
                depth--;
            } else if (current == '=' && depth == 0) {
                declaration = declaration.substring(0, i).trim();
                break;
            }
        }

        if (!declaration.endsWith(";")) {
            declaration += ";";
        }
        declarations.add(declaration);
    }

    private List<String> extractExceptions(String source) {
        String code = maskCommentsAndLiterals(source);
        Pattern catchPattern = Pattern.compile(
                "\\bcatch\\s*\\(\\s*([\\w.$]+(?:\\s*\\|\\s*[\\w.$]+)*)\\s+([A-Za-z_$][\\w$]*)\\s*\\)");
        Matcher matcher = catchPattern.matcher(code);
        Map<String, String> unique = new LinkedHashMap<>();

        while (matcher.find()) {
            String type = matcher.group(1).replaceAll("\\s+", "");
            String variable = matcher.group(2);
            unique.putIfAbsent(type, type + " " + variable + ";");
        }

        return new ArrayList<>(unique.values());
    }

    private String maskCommentsAndLiterals(String source) {
        char[] code = source.toCharArray();
        int i = 0;

        // Se sustituyen comentarios y literales por espacios sin cambiar las posiciones.
        while (i < code.length) {
            if (code[i] == '/' && i + 1 < code.length && code[i + 1] == '/') {
                while (i < code.length && code[i] != '\n') {
                    code[i++] = ' ';
                }
            } else if (code[i] == '/' && i + 1 < code.length && code[i + 1] == '*') {
                code[i++] = ' ';
                code[i++] = ' ';
                while (i < code.length && !(code[i] == '*' && i + 1 < code.length
                        && code[i + 1] == '/')) {
                    if (code[i] != '\n') {
                        code[i] = ' ';
                    }
                    i++;
                }
                if (i < code.length) {
                    code[i++] = ' ';
                    code[i++] = ' ';
                }
            } else if (code[i] == '"' || code[i] == '\'') {
                char quote = code[i];
                code[i++] = ' ';
                while (i < code.length) {
                    if (code[i] == '\\') {
                        code[i++] = ' ';
                        if (i < code.length) {
                            code[i++] = ' ';
                        }
                    } else if (code[i] == quote) {
                        code[i++] = ' ';
                        break;
                    } else {
                        if (code[i] != '\n') {
                            code[i] = ' ';
                        }
                        i++;
                    }
                }
            } else {
                i++;
            }
        }

        return new String(code);
    }

    public static void main(String[] args) {
        try {
            new Ejercicio3().show();
        } catch (IOException e) {
            System.err.printf("Error al procesar el boletín: %s%n", e.getMessage());
        }
    }
}
```

### Explicación paso a paso

1. **Localizar fuentes:** el programa busca los `.java` directamente dentro de `src/ejercicios1_FicherosTexto`. Ajusta `sourceDirectory` si tu IDE utiliza otra carpeta de fuentes.
2. **Concatenar:** ordena los nombres para que el resultado siempre tenga el mismo orden, lee cada clase con `BufferedReader` y escribe el fichero combinado con `BufferedWriter`.
3. **Analizar `try-with-resources`:** se localiza cada `try (` y se recorren sus paréntesis balanceados. Los `;` que están al nivel de los recursos separan las declaraciones. Se elimina la inicialización para producir, por ejemplo, `BufferedReader reader;`.
4. **Analizar `catch`:** se extrae el tipo y el nombre de variable. El `LinkedHashMap` deja una sola declaración por tipo de excepción.
5. **Ignorar texto que no es código:** los comentarios y literales se enmascaran antes de buscar `try` y `catch`, evitando coincidencias accidentales dentro de cadenas.
6. **Guardar resultados:** se crean los dos ficheros de salida dentro de `files`.

> [!info] Archivos de salida
> El programa vuelve a generar `boletin_completo.txt` desde cero en cada ejecución y reemplaza los dos informes anteriores.

## Ejercicio 4: Repartir y reconstruir un fichero con buffers

> [!question] Enunciado
> Copia un fichero de texto en tres ficheros: el primero recibirá los primeros 5 caracteres de cada grupo de 15, el segundo los 5 siguientes y el tercero los 5 últimos. Continúa hasta copiar todo el contenido. Utiliza lectura sin desplazamiento y escrituras con desplazamiento de un buffer de 15 caracteres.
>
> Después, reconstruye el fichero original a partir de los tres ficheros usando lecturas con desplazamiento y escritura sin desplazamiento de un buffer de 15 caracteres. Comprueba mediante código que el reconstruido y el original son iguales. En la última lectura, si el buffer queda incompleto, no escribas caracteres sobrantes.

### Clases y métodos introducidos

- `BufferedReader.read`: carga caracteres en un buffer, con o sin desplazamiento.
- `BufferedWriter.write`: escribe el buffer completo o un segmento indicado por desplazamiento y longitud.
- `System.arraycopy`: compacta los segmentos válidos del buffer.
- `Files.readString`: permite comparar el contenido original y el reconstruido.

> **Términos explicados:** [[01 - Ficheros#7.4 Clases BufferedReader y BufferedWriter|buffer y lectura/escritura con buffer]] · [[01 - Ficheros#7.5 Operaciones con arrays y desplazamientos|desplazamiento (`offset`) y longitud]] · [[#Ejercicio 4: Repartir y reconstruir un fichero con buffers|longitud válida y compactación de datos]]

#### Ejemplo simple de funcionamiento
```java
char[] buffer = new char[15];
int count = reader.read(buffer);
if (count > 0) {
    writer.write(buffer, 0, count);
}
```

### Conceptos clave

- `read(char[] buffer)`: lee en el buffer desde su posición inicial.
- `write(char[] buffer, int off, int len)`: escribe un segmento del buffer.
- `read(char[] buffer, int off, int len)`: lee un segmento y lo deposita a partir de `off`.
- `write(char[] buffer)`: escribe el array completo; por eso, al reconstruir, se compactan primero los caracteres válidos y se usa un array del tamaño exacto.
- En el último grupo puede haber menos de 15 caracteres. Se calcula la longitud válida de cada segmento para no copiar datos sobrantes.

### Código (`Ejercicio4.java`)

```java
package ejercicios1_FicherosTexto;

import java.io.BufferedReader;
import java.io.BufferedWriter;
import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;

public class Ejercicio4 {

    private static final int BUFFER_SIZE = 15;
    private static final int PART_SIZE = 5;

    public void show() throws IOException {
        Path original = Paths.get("files", "original.txt");
        Path part1 = Paths.get("files", "parte1.txt");
        Path part2 = Paths.get("files", "parte2.txt");
        Path part3 = Paths.get("files", "parte3.txt");
        Path reconstructed = Paths.get("files", "reconstruido.txt");

        Files.createDirectories(original.getParent());
        split(original, part1, part2, part3);
        reconstruct(part1, part2, part3, reconstructed);

        // La comparación completa verifica también los caracteres finales y los saltos de línea.
        boolean equal = Files.readString(original, StandardCharsets.UTF_8)
                .equals(Files.readString(reconstructed, StandardCharsets.UTF_8));
        System.out.println("¿El fichero reconstruido es igual al original?: " + equal);
    }

    private void split(Path original, Path part1, Path part2, Path part3) throws IOException {
        try (BufferedReader reader = Files.newBufferedReader(original, StandardCharsets.UTF_8);
             BufferedWriter writer1 = Files.newBufferedWriter(part1, StandardCharsets.UTF_8);
             BufferedWriter writer2 = Files.newBufferedWriter(part2, StandardCharsets.UTF_8);
             BufferedWriter writer3 = Files.newBufferedWriter(part3, StandardCharsets.UTF_8)) {

            char[] buffer = new char[BUFFER_SIZE];
            int read;

            // La lectura no usa desplazamiento: cada grupo comienza en buffer[0].
            while ((read = reader.read(buffer)) != -1) {
                writePart(writer1, buffer, 0, Math.min(PART_SIZE, read));
                writePart(writer2, buffer, PART_SIZE,
                        Math.max(0, Math.min(PART_SIZE, read - PART_SIZE)));
                writePart(writer3, buffer, PART_SIZE * 2,
                        Math.max(0, read - PART_SIZE * 2));
            }
        }
    }

    private void writePart(BufferedWriter writer, char[] buffer, int offset, int length)
            throws IOException {
        if (length > 0) {
            // El desplazamiento selecciona cuál de los tres segmentos se escribe.
            writer.write(buffer, offset, length);
        }
    }

    private void reconstruct(Path part1, Path part2, Path part3, Path destination)
            throws IOException {
        try (BufferedReader reader1 = Files.newBufferedReader(part1, StandardCharsets.UTF_8);
             BufferedReader reader2 = Files.newBufferedReader(part2, StandardCharsets.UTF_8);
             BufferedReader reader3 = Files.newBufferedReader(part3, StandardCharsets.UTF_8);
             BufferedWriter writer = Files.newBufferedWriter(destination, StandardCharsets.UTF_8)) {

            char[] buffer = new char[BUFFER_SIZE];

            while (true) {
                // Cada segmento se coloca en su zona del buffer mediante desplazamiento.
                int count1 = readUpToFive(reader1, buffer, 0);
                int count2 = readUpToFive(reader2, buffer, PART_SIZE);
                int count3 = readUpToFive(reader3, buffer, PART_SIZE * 2);

                if (count1 == -1 && count2 == -1 && count3 == -1) {
                    break;
                }

                int validCount = Math.max(0, count1)
                        + Math.max(0, count2)
                        + Math.max(0, count3);
                char[] compact = new char[validCount];
                int destinationOffset = 0;

                // Se compactan los tramos válidos para que write(char[]) no escriba basura.
                if (count1 > 0) {
                    System.arraycopy(buffer, 0, compact, destinationOffset, count1);
                    destinationOffset += count1;
                }
                if (count2 > 0) {
                    System.arraycopy(buffer, PART_SIZE, compact, destinationOffset, count2);
                    destinationOffset += count2;
                }
                if (count3 > 0) {
                    System.arraycopy(buffer, PART_SIZE * 2, compact, destinationOffset, count3);
                }

                // Escritura sin desplazamiento: compact contiene solo caracteres válidos.
                writer.write(compact);
            }
        }
    }

    private int readUpToFive(BufferedReader reader, char[] buffer, int offset) throws IOException {
        int total = 0;

        // Se repite por si una lectura entrega menos caracteres que los solicitados.
        while (total < PART_SIZE) {
            int read = reader.read(buffer, offset + total, PART_SIZE - total);
            if (read == -1) {
                return total == 0 ? -1 : total;
            }
            total += read;
        }

        return total;
    }

    public static void main(String[] args) {
        try {
            new Ejercicio4().show();
        } catch (IOException e) {
            System.err.printf("Error al dividir o reconstruir el fichero: %s%n", e.getMessage());
        }
    }
}
```

### Explicación paso a paso

1. **Dividir en grupos:** `reader.read(buffer)` llena el buffer desde el índice 0. Para cada grupo se escriben como máximo 5 caracteres en cada fichero.
2. **Tratar el último grupo:** las expresiones `Math.min` calculan cuántos caracteres válidos hay en cada segmento; si no hay ninguno, no se realiza la escritura.
3. **Leer con desplazamiento:** `readUpToFive` coloca hasta 5 caracteres en cada zona del buffer. Repite la lectura si se reciben menos caracteres de los solicitados.
4. **Compactar:** como las zonas del buffer tienen huecos cuando una parte está incompleta, `System.arraycopy` copia únicamente los caracteres válidos a un array compacto.
5. **Escribir sin desplazamiento:** `writer.write(compact)` escribe el array exacto, evitando que los caracteres antiguos que queden en el buffer se añadan al destino.
6. **Verificar:** se comparan el contenido UTF-8 del original y el reconstruido.

## Esquema comparativo de conceptos clave

| Necesidad | API utilizada | Idea principal |
| --- | --- | --- |
| Copiar o concatenar texto | `Files.copy`, `Files.writeString`, `Files.write` | Elegir el método y las opciones según exista el destino y se quiera añadir o reemplazar. |
| Cifrar con una clave repetida | `char[]`, `i % key.length()` | Sumar la clave para cifrar y restarla para descifrar. |
| Leer y escribir secuencialmente | `BufferedReader`, `BufferedWriter` | Procesar texto por líneas o por segmentos de caracteres. |
| Analizar código fuente | `Pattern`, `Matcher`, paréntesis balanceados | Extraer recursos y excepciones sin confundirlos con texto de comentarios y literales. |
| Repartir y reconstruir caracteres | `read` y `write` con `off` y `len` | Controlar qué zona del buffer se lee o se escribe. |
