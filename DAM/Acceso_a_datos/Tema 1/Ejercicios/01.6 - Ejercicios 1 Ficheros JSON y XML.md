## Ejercicio 1: Agenda telefónica en un fichero JSON

> [!question] Enunciado
> Crea un fichero json con los datos de la agenda telefónica. A continuación, lee el fichero json y muestra los datos por consola.

### Clases y métodos introducidos

- `ObjectMapper` (Jackson): convierte objetos Java en JSON y al revés.
- `writeValueAsString(objeto)`: **serializa** la lista de contactos a una cadena JSON.
- `readValue(cadena, new TypeReference<List<Contact>>() {})`: **deserializa** la cadena a una `List<Contact>`.
- `JavaTimeModule` + `@JsonFormat(pattern = "dd/MM/yyyy")`: permiten guardar y leer `LocalDate`.
- `SerializationFeature.INDENT_OUTPUT`: escribe el JSON con saltos de línea y sangría (no viene en la teoría; es opcional).

> **Términos explicados:** [[01 - Ficheros#11.2 Ficheros JSON|Ficheros JSON]] · [[01 - Ficheros#11.3 Biblioteca Jackson|Biblioteca Jackson]] · [[01 - Ficheros#7. Ficheros de texto|`Files.writeString` y `Files.readAllLines`]]

#### Ejemplo simple de funcionamiento
```java
ObjectMapper mapper = new ObjectMapper();
String json = mapper.writeValueAsString(List.of("Ana", "Luis")); // ["Ana","Luis"]
List<String> names = mapper.readValue(json, new TypeReference<List<String>>() {});
```

### Conceptos clave

- Un JSON es **texto**: se escribe y se lee con los mismos métodos de `Files` que un fichero de texto. Jackson solo hace la conversión objeto ⇄ cadena.
- Jackson crea los objetos al leer con el **constructor vacío** y rellena los atributos después. Sin él, `readValue` falla.
- Los nombres de las claves salen de los *getters* (`getName` → `"name"`, `isMoneyOwed` → `"moneyOwed"`).
- `TypeReference<List<Contact>>` le dice a Jackson el tipo **completo** de la lista; con `List.class` no sabría que dentro hay `Contact` y devolvería mapas.
- `LocalDate` no lo entiende Jackson por defecto: hay que registrar `JavaTimeModule` en el mapper.

### Código (`Contact.java`)

```java
package ficherosJsonYXml.ejercicio1;

import java.time.LocalDate;
import java.time.format.DateTimeFormatter;
import com.fasterxml.jackson.annotation.JsonFormat;

// Un contacto de la agenda telefónica
public class Contact {
    private String name;
    private String phone;
    private String address;
    private int postalCode;

    @JsonFormat(pattern = "dd/MM/yyyy") // Patrón con el que se escribe y se lee la fecha
    private LocalDate birthDate;

    private boolean moneyOwed;  // si le debo dinero
    private double amountOwed;  // cuánto le debo

    public Contact(String name, String phone, String address, int postalCode,
                   LocalDate birthDate, boolean moneyOwed, double amountOwed) {
        this.name = name;
        this.phone = phone;
        this.address = address;
        this.postalCode = postalCode;
        this.birthDate = birthDate;
        this.moneyOwed = moneyOwed;
        this.amountOwed = amountOwed;
    }

    // Constructor vacío (obligatorio para Jackson)
    public Contact() {
    }

    public String getName() {
        return name;
    }

    public String getPhone() {
        return phone;
    }

    public String getAddress() {
        return address;
    }

    public int getPostalCode() {
        return postalCode;
    }

    public LocalDate getBirthDate() {
        return birthDate;
    }

    public boolean isMoneyOwed() {
        return moneyOwed;
    }

    public double getAmountOwed() {
        return amountOwed;
    }

    @Override
    public String toString() {
        DateTimeFormatter formatter = DateTimeFormatter.ofPattern("dd/MM/yyyy");
        return String.format("%s%n\tTeléfono: %s%n\tDirección: %s%n\tCódigo postal: %d%n"
                        + "\tFecha de nacimiento: %s%n\t¿Le debo dinero?: %s%n\tCantidad: %.2f €",
                name, phone, address, postalCode, formatter.format(birthDate),
                moneyOwed ? "Si" : "No", amountOwed);
    }
}
```

### Código (`Ejercicio1.java`)

```java
package ficherosJsonYXml.ejercicio1;

import java.io.*;
import java.nio.file.*;
import java.time.LocalDate;
import java.util.ArrayList;
import java.util.List;
import com.fasterxml.jackson.core.type.TypeReference;
import com.fasterxml.jackson.databind.ObjectMapper;
import com.fasterxml.jackson.databind.SerializationFeature;
import com.fasterxml.jackson.datatype.jsr310.JavaTimeModule;

public class Ejercicio1 {

    private final Path file = Paths.get("files", "agenda.json");

    public void show() {
        List<Contact> contacts = generateContacts();
        writeJson(contacts); // Escribe los contactos en el fichero json
        readJson();          // Lee el fichero json y muestra los contactos por consola
    }

    private List<Contact> generateContacts() {
        List<Contact> contacts = new ArrayList<>();
        contacts.add(new Contact("Ana López", "600111222", "C/ Real 12, Algeciras",
                11201, LocalDate.of(1998, 3, 14), true, 25.50));
        contacts.add(new Contact("Luis Pérez", "611333444", "Av. Virgen del Carmen 3, Algeciras",
                11202, LocalDate.of(2001, 11, 2), false, 0));
        contacts.add(new Contact("Marta Ruiz", "622555666", "C/ Ancha 7, La Línea",
                11300, LocalDate.of(1995, 7, 30), true, 120.75));
        return contacts;
    }

    private ObjectMapper createMapper() {
        ObjectMapper mapper = new ObjectMapper();
        mapper.registerModule(new JavaTimeModule());         // Necesario para LocalDate
        mapper.enable(SerializationFeature.INDENT_OUTPUT);   // json con saltos de línea y sangría
        return mapper;
    }

    private void writeJson(List<Contact> contacts) {
        ObjectMapper mapper = createMapper();
        String json;
        try {
            Files.createDirectories(file.getParent()); // Files.writeString no crea la carpeta "files"
            json = mapper.writeValueAsString(contacts); // Convierte la lista en una cadena json
            Files.writeString(file, json);              // Escribe la cadena en el fichero
        } catch (IOException e) {
            System.err.printf("Error de entrada/salida: %s%n", e.getMessage());
        }
    }

    private void readJson() {
        ObjectMapper mapper = createMapper();
        List<String> lines;
        String json;
        List<Contact> contacts;
        try {
            lines = Files.readAllLines(file);  // Lee todas las líneas del fichero
            json = String.join("", lines);     // Las une en una sola cadena
            // Convierte la cadena json en una lista de contactos
            contacts = mapper.readValue(json, new TypeReference<List<Contact>>() {});
            System.out.println("Contenido de la agenda (json):");
            contacts.forEach(System.out::println);
        } catch (NoSuchFileException e) {
            System.err.printf("El fichero no existe: %s%n", e.getMessage());
        } catch (IOException e) {
            System.err.printf("Error de entrada/salida: %s%n", e.getMessage());
        }
    }

    public static void main(String[] args) {
        new Ejercicio1().show();
    }
}
```

### Explicación paso a paso

1. **`Contact` tiene los mismos 7 datos que la agenda binaria**, pero la fecha ahora es un `LocalDate` (en el binario era un `String`). `@JsonFormat` fija cómo se escribe: `"14/03/1998"` en vez de `[1998,3,14]`.
2. **Los atributos ya no son `final`** y hay un **constructor vacío**: Jackson necesita crear un `Contact` "en blanco" y rellenarlo campo a campo al leer.
3. **`show` reparte el trabajo** como `JsonFile` en la teoría: generar los contactos, escribir el JSON y leerlo.
4. **`createMapper` evita repetir código**: los dos métodos necesitan un `ObjectMapper` con `JavaTimeModule` registrado. `INDENT_OUTPUT` solo cambia el aspecto del fichero.
5. **`writeJson`** crea la carpeta `files/` (`Files.writeString` no la crea), convierte la lista en una cadena con `writeValueAsString` y la guarda con `Files.writeString`.
6. **`readJson`** hace lo contrario: `readAllLines` + `String.join` para tener todo el JSON en una cadena, y `readValue` con `TypeReference` para obtener la `List<Contact>`. Cada contacto se imprime con su `toString`.
7. **Si el fichero no existe**, `Files.readAllLines` lanza `NoSuchFileException` (no `FileNotFoundException`, que es de los flujos `java.io`). Va antes que `IOException` porque es hija suya.

> [!tip] Prueba
> Ejecuta `Ejercicio1`: salen los 3 contactos bajo "Contenido de la agenda (json):" y se crea `files/agenda.json`:
> ```json
> [ {
>   "name" : "Ana López",
>   "phone" : "600111222",
>   "address" : "C/ Real 12, Algeciras",
>   "postalCode" : 11201,
>   "birthDate" : "14/03/1998",
>   "moneyOwed" : true,
>   "amountOwed" : 25.5
> }, {
>   "name" : "Luis Pérez",
>   …
> } ]
> ```
> Prueba a quitar el constructor vacío de `Contact`: la escritura funciona, pero la lectura falla con `InvalidDefinitionException` (*cannot deserialize… no Creators*).

## Ejercicio 2: Agenda telefónica en un fichero XML

> [!question] Enunciado
> Crea un fichero xml con los datos de la agenda telefónica. A continuación, lee el fichero xml y muestra los datos por consola.

### Clases y métodos introducidos

- `XmlMapper` (módulo `jackson-dataformat-xml`): igual que `ObjectMapper`, pero genera y lee XML.
- `@JacksonXmlRootElement(localName = "…")`: nombre de la etiqueta raíz.
- `@JacksonXmlProperty(localName = "…")`: nombre de la etiqueta de cada atributo.
- `@JacksonXmlElementWrapper(useWrapping = false)`: quita la etiqueta extra que envolvería a la lista.
- `readValue(cadena, ContactList.class)`: lee el XML a un objeto de la clase envoltorio.

> **Términos explicados:** [[01 - Ficheros#11.1 Ficheros XML|Ficheros XML]] · [[01 - Ficheros#11.3 Biblioteca Jackson|Biblioteca Jackson]]

#### Ejemplo simple de funcionamiento
```java
XmlMapper xmlMapper = new XmlMapper();
String xml = xmlMapper.writeValueAsString(new ContactList(contacts)); // <Agenda><Contact>…</Contact></Agenda>
ContactList read = xmlMapper.readValue(xml, ContactList.class);
```

### Conceptos clave

- Un XML necesita **una sola raíz**. Si se serializa la lista tal cual, Jackson usa `<ArrayList>` y `<item>`; para tener `<Agenda>` y `<Contact>` se envuelve la lista en `ContactList`.
- Sin `useWrapping = false`, cada contacto quedaría dentro de una etiqueta extra con el nombre del atributo: `<Agenda><Contact><Contact>…`.
- Se lee **con la misma clase con la que se escribió** (`ContactList.class`). Así no hace falta `TypeReference`: el tipo de la lista lo da el atributo `List<Contact> contacts`.
- Las anotaciones `@JsonFormat` y el `JavaTimeModule` funcionan igual con `XmlMapper`.

### Código (`Contact.java`)

```java
package ficherosJsonYXml.ejercicio2;

import java.time.LocalDate;
import java.time.format.DateTimeFormatter;
import com.fasterxml.jackson.annotation.JsonFormat;
import com.fasterxml.jackson.dataformat.xml.annotation.*;

// Un contacto de la agenda telefónica
@JacksonXmlRootElement(localName = "Contact") // Etiqueta raíz si se escribe un solo contacto
public class Contact {
    @JacksonXmlProperty(localName = "Name") // Etiqueta personalizada
    private String name;
    @JacksonXmlProperty(localName = "Phone") // Etiqueta personalizada
    private String phone;
    @JacksonXmlProperty(localName = "Address") // Etiqueta personalizada
    private String address;
    @JacksonXmlProperty(localName = "PostalCode") // Etiqueta personalizada
    private int postalCode;

    @JacksonXmlProperty(localName = "BirthDate") // Etiqueta personalizada
    @JsonFormat(pattern = "dd/MM/yyyy") // Patrón con el que se escribe y se lee la fecha
    private LocalDate birthDate;

    @JacksonXmlProperty(localName = "MoneyOwed") // Etiqueta personalizada
    private boolean moneyOwed;  // si le debo dinero
    @JacksonXmlProperty(localName = "AmountOwed") // Etiqueta personalizada
    private double amountOwed;  // cuánto le debo

    public Contact(String name, String phone, String address, int postalCode,
                   LocalDate birthDate, boolean moneyOwed, double amountOwed) {
        this.name = name;
        this.phone = phone;
        this.address = address;
        this.postalCode = postalCode;
        this.birthDate = birthDate;
        this.moneyOwed = moneyOwed;
        this.amountOwed = amountOwed;
    }

    // Constructor vacío (obligatorio para Jackson)
    public Contact() {
    }

    public String getName() {
        return name;
    }

    public String getPhone() {
        return phone;
    }

    public String getAddress() {
        return address;
    }

    public int getPostalCode() {
        return postalCode;
    }

    public LocalDate getBirthDate() {
        return birthDate;
    }

    public boolean isMoneyOwed() {
        return moneyOwed;
    }

    public double getAmountOwed() {
        return amountOwed;
    }

    @Override
    public String toString() {
        DateTimeFormatter formatter = DateTimeFormatter.ofPattern("dd/MM/yyyy");
        return String.format("%s%n\tTeléfono: %s%n\tDirección: %s%n\tCódigo postal: %d%n"
                        + "\tFecha de nacimiento: %s%n\t¿Le debo dinero?: %s%n\tCantidad: %.2f €",
                name, phone, address, postalCode, formatter.format(birthDate),
                moneyOwed ? "Si" : "No", amountOwed);
    }
}
```

### Código (`ContactList.java`)

```java
package ficherosJsonYXml.ejercicio2;

import java.util.List;
import com.fasterxml.jackson.dataformat.xml.annotation.*;

@JacksonXmlRootElement(localName = "Agenda") // Etiqueta raíz del xml
public class ContactList {
    @JacksonXmlElementWrapper(useWrapping = false) // Quita el nodo que envolvería a la lista
    @JacksonXmlProperty(localName = "Contact")     // Etiqueta de cada contacto
    private List<Contact> contacts;

    // Constructor vacío (obligatorio para Jackson)
    public ContactList() {
    }

    public ContactList(List<Contact> contacts) {
        this.contacts = contacts;
    }

    public List<Contact> getContacts() {
        return contacts;
    }

    public void setContacts(List<Contact> contacts) {
        this.contacts = contacts;
    }
}
```

### Código (`Ejercicio2.java`)

```java
package ficherosJsonYXml.ejercicio2;

import java.io.*;
import java.nio.file.*;
import java.time.LocalDate;
import java.util.ArrayList;
import java.util.List;
import com.fasterxml.jackson.databind.SerializationFeature;
import com.fasterxml.jackson.dataformat.xml.XmlMapper;
import com.fasterxml.jackson.datatype.jsr310.JavaTimeModule;

public class Ejercicio2 {

    private final Path file = Paths.get("files", "agenda.xml");

    public void show() {
        ContactList contactList = generateContacts();
        writeXml(contactList); // Escribe los contactos en el fichero xml
        readXml();             // Lee el fichero xml y muestra los contactos por consola
    }

    private ContactList generateContacts() {
        List<Contact> contacts = new ArrayList<>();
        contacts.add(new Contact("Ana López", "600111222", "C/ Real 12, Algeciras",
                11201, LocalDate.of(1998, 3, 14), true, 25.50));
        contacts.add(new Contact("Luis Pérez", "611333444", "Av. Virgen del Carmen 3, Algeciras",
                11202, LocalDate.of(2001, 11, 2), false, 0));
        contacts.add(new Contact("Marta Ruiz", "622555666", "C/ Ancha 7, La Línea",
                11300, LocalDate.of(1995, 7, 30), true, 120.75));
        return new ContactList(contacts); // La lista va envuelta para tener la raíz <Agenda>
    }

    private XmlMapper createMapper() {
        XmlMapper xmlMapper = new XmlMapper();
        xmlMapper.registerModule(new JavaTimeModule());        // Necesario para LocalDate
        xmlMapper.enable(SerializationFeature.INDENT_OUTPUT);  // xml con saltos de línea y sangría
        return xmlMapper;
    }

    private void writeXml(ContactList contactList) {
        XmlMapper xmlMapper = createMapper();
        String xml;
        try {
            Files.createDirectories(file.getParent());       // Files.writeString no crea la carpeta "files"
            xml = xmlMapper.writeValueAsString(contactList); // Convierte la agenda en una cadena xml
            Files.writeString(file, xml);                    // Escribe la cadena en el fichero
        } catch (IOException e) {
            System.err.printf("Error de entrada/salida: %s%n", e.getMessage());
        }
    }

    private void readXml() {
        XmlMapper xmlMapper = createMapper();
        List<String> lines;
        String xml;
        ContactList contactList;
        try {
            lines = Files.readAllLines(file); // Lee todas las líneas del fichero
            xml = String.join("", lines);     // Las une en una sola cadena
            // Se lee con la misma clase con la que se escribió: ContactList
            contactList = xmlMapper.readValue(xml, ContactList.class);
            System.out.println("Contenido de la agenda (xml):");
            contactList.getContacts().forEach(System.out::println);
        } catch (NoSuchFileException e) {
            System.err.printf("El fichero no existe: %s%n", e.getMessage());
        } catch (IOException e) {
            System.err.printf("Error de entrada/salida: %s%n", e.getMessage());
        }
    }

    public static void main(String[] args) {
        new Ejercicio2().show();
    }
}
```

### Explicación paso a paso

1. **`Contact` es el del ejercicio 1 con etiquetas XML.** Cada atributo lleva `@JacksonXmlProperty` para que la etiqueta salga en mayúscula (`<Name>`, `<PostalCode>`…), como `Vehicle` en la teoría.
2. **`ContactList` envuelve la lista** y pone la raíz `<Agenda>`. `@JacksonXmlProperty(localName = "Contact")` da nombre a cada elemento y `useWrapping = false` evita el nodo intermedio.
3. **`generateContacts` devuelve un `ContactList`**, no una lista suelta, porque eso es lo que se escribe.
4. **`writeXml`** es igual que `writeJson` cambiando `ObjectMapper` por `XmlMapper`: `writeValueAsString` + `Files.writeString`.
5. **`readXml`** lee el fichero en una cadena y la deserializa con `readValue(xml, ContactList.class)`; después recorre `getContacts()` para mostrar cada contacto.

> [!warning] Diferencia con la teoría
> En `XmlFile` de los apuntes se escribe un `VehicleList` pero se lee con `TypeReference<List<Vehicle>>`. Aquí se lee con `ContactList.class`, que es la misma clase que se escribió: es más directo y no depende de cómo Jackson interprete la raíz.

## Esquema comparativo de conceptos clave

| Necesidad | API utilizada | Idea principal |
| --- | --- | --- |
| Objetos → JSON | `ObjectMapper.writeValueAsString` | Devuelve una cadena; se guarda con `Files.writeString`. |
| JSON → lista de objetos | `readValue(json, new TypeReference<List<Contact>>() {})` | `TypeReference` indica el tipo genérico completo. |
| Objetos → XML | `XmlMapper.writeValueAsString` | Mismos métodos que `ObjectMapper`. |
| XML → objetos | `readValue(xml, ContactList.class)` | Se lee con la clase envoltorio que se escribió. |
| Raíz y etiquetas del XML | `@JacksonXmlRootElement`, `@JacksonXmlProperty` | `localName` da el nombre de la etiqueta. |
| Quitar el nodo de la lista | `@JacksonXmlElementWrapper(useWrapping = false)` | Los `<Contact>` cuelgan directamente de `<Agenda>`. |
| Fechas `LocalDate` | `JavaTimeModule` + `@JsonFormat(pattern = "dd/MM/yyyy")` | Sin el módulo, Jackson no sabe convertir la fecha. |
| Crear el objeto al leer | Constructor vacío | Jackson crea el objeto y luego rellena sus atributos. |
| Fichero legible | `SerializationFeature.INDENT_OUTPUT` | Saltos de línea y sangría (opcional). |
