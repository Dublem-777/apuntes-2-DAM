## Ejercicio 1: Agenda telefónica en un fichero de acceso aleatorio

> [!question] Enunciado
> Realiza la agenda telefónica en un fichero de acceso aleatorio. Realiza el siguiente menú:
>
> 1. Consultar el fichero
> 2. Consultar un contacto
> 3. Añadir un contacto
> 4. Modificar un contacto
> 5. Modificar dinero
>
> En la opción 1, se muestra por consola el contenido del fichero. En la opción 2, se le pide al usuario el identificador del contacto a mostrar. En la opción 3, se le piden los datos al usuario y se añade el contacto por el final. En la opción 4, se modifica el contacto entero por otro elegido por el usuario. En la opción 5, se modifica si le debo dinero y la cantidad.
>
> Cuando se le pida al usuario el identificador del contacto que desea, hay que mostrarle el rango de identificadores válidos.

### Clases y métodos introducidos

- `RandomAccessFile` en modo `"r"` (consultas) y `"rw"` (añadir y modificar).
- `seek`, `getFilePointer` y `length`: colocan el puntero y detectan el final del fichero.
- `StringBuilder.setLength`: rellena las cadenas hasta una longitud fija para que todos los contactos ocupen lo mismo.

> **Términos explicados:** [[01 - Ficheros#10. Ficheros de acceso aleatorio|`RandomAccessFile`, puntero y registros de tamaño fijo]]

> [!tip] Pista
> Calcula primero cuántos bytes ocupa un contacto (identificador + campos, con las cadenas a longitud fija). Con ese tamaño:
> - Contacto `id` → `seek((id - 1) * TAMAÑO)`.
> - Último identificador (rango válido) → `seek(length() - TAMAÑO)` y `readInt()`.
> - Añadir → `seek(length())` y escribir.
> - Modificar dinero → saltar hasta la posición del booleano dentro del registro y sobrescribir solo esos campos.

#### Ejemplo simple de funcionamiento
```java
try (RandomAccessFile raf = new RandomAccessFile("agenda.dat", "rw")) {
    raf.seek((long) (3 - 1) * 207); // salta directamente al contacto 3
    int id = raf.readInt();         // lee su identificador
    raf.seek(raf.length());         // final del fichero: aquí se añade
}
```

### Conceptos clave

- **Registro de tamaño fijo**: si todos los contactos ocupan lo mismo, la posición de cualquiera se calcula con una multiplicación, sin leer los anteriores. Es como las taquillas de un gimnasio: todas son iguales, así que la taquilla 3 está justo después de las dos primeras.
- Cada cadena se guarda con `writeChars` a una **longitud fija** (2 bytes por carácter). `StringBuilder.setLength` rellena las cortas y recorta las largas.
- Diseño del registro (207 bytes):

  | Campo | Tipo | Bytes | Empieza en el byte |
  | --- | --- | --- | --- |
  | identificador | `int` | 4 | 0 |
  | nombre (30 car.) | `char` ×30 | 60 | 4 |
  | teléfono (15 car.) | `char` ×15 | 30 | 64 |
  | dirección (40 car.) | `char` ×40 | 80 | 94 |
  | código postal | `int` | 4 | 174 |
  | fecha (10 car.) | `char` ×10 | 20 | 178 |
  | ¿le debo? | `boolean` | 1 | **198** |
  | cantidad | `double` | 8 | 199 |

- `seek(pos)` coloca el puntero, `skipBytes(n)` lo avanza, `length()` es el final y `getFilePointer()` dice dónde está.
- Modo `"r"` para consultar (el fichero tiene que existir) y `"rw"` para añadir o modificar (lo crea si no existe).

### Código (`Constants.java`)

```java
package ficherosDeAccesoAleatorio.ejercicio1;

public final class Constants {
    // Longitud fija (en caracteres) de cada cadena del contacto
    public static final int LEN_NAME = 30;
    public static final int LEN_PHONE = 15;
    public static final int LEN_ADDRESS = 40;
    public static final int LEN_BIRTH_DATE = 10;

    // Número de bytes que ocupa el identificador (int)
    public static final int IDENTIFIER = 4;

    // Número de bytes que ocupa cada contacto:
    // id (4) + cadenas (2 bytes por char) + código postal int (4) + boolean (1) + double (8) = 207
    public static final int NUM_BYTES_CONTACT =
            IDENTIFIER + (LEN_NAME + LEN_PHONE + LEN_ADDRESS + LEN_BIRTH_DATE) * 2 + 4 + 1 + 8;

    // Número de bytes donde se encuentra "si le debo dinero" dentro de un contacto:
    // id (4) + nombre (60) + teléfono (30) + dirección (80) + código postal (4) + fecha (20) = 198
    public static final int POSITION_MONEY_OWED =
            IDENTIFIER + (LEN_NAME + LEN_PHONE + LEN_ADDRESS) * 2 + 4 + LEN_BIRTH_DATE * 2;

    private Constants() {
    }
}
```

### Código (`Contact.java`)

```java
package ficherosDeAccesoAleatorio.ejercicio1;

// Un contacto de la agenda (el identificador no va aquí: lo da su posición en el fichero)
public class Contact {
    private final String name;
    private final String phone;
    private final String address;
    private final int postalCode;
    private final String birthDate;   // dd/MM/yyyy
    private final boolean moneyOwed;  // si le debo dinero
    private final double amountOwed;  // cuánto le debo

    public Contact(String name, String phone, String address, int postalCode,
                   String birthDate, boolean moneyOwed, double amountOwed) {
        this.name = name;
        this.phone = phone;
        this.address = address;
        this.postalCode = postalCode;
        this.birthDate = birthDate;
        this.moneyOwed = moneyOwed;
        this.amountOwed = amountOwed;
    }

    public String getName() {
        return name;
    }

    public String getPhone() {
        return phone;
    }

    public String getAddress() {
        return address;
    }

    public int getPostalCode() {
        return postalCode;
    }

    public String getBirthDate() {
        return birthDate;
    }

    public boolean isMoneyOwed() {
        return moneyOwed;
    }

    public double getAmountOwed() {
        return amountOwed;
    }

    @Override
    public String toString() {
        return String.format("%s%n\tTeléfono: %s%n\tDirección: %s%n\tCódigo postal: %d%n"
                        + "\tFecha de nacimiento: %s%n\t¿Le debo dinero?: %s%n\tCantidad: %.2f €",
                name, phone, address, postalCode, birthDate, moneyOwed ? "Si" : "No", amountOwed);
    }
}
```

### Código (`Ejercicio1.java`)

```java
package ficherosDeAccesoAleatorio.ejercicio1;

import static ficherosDeAccesoAleatorio.ejercicio1.Constants.*;

import java.io.*;
import java.nio.file.*;
import java.util.Scanner;

public class Ejercicio1 {

    private final Path file = Paths.get("files", "agendaAleatoria.dat");
    private final Scanner keyboard = new Scanner(System.in);

    public void show() {
        int option;
        do {
            System.out.println("\n--- AGENDA TELEFÓNICA (acceso aleatorio) ---");
            System.out.println("1. Consultar el fichero");
            System.out.println("2. Consultar un contacto");
            System.out.println("3. Añadir un contacto");
            System.out.println("4. Modificar un contacto");
            System.out.println("5. Modificar dinero");
            System.out.println("0. Salir");
            option = readInt("Elige una opción: ");

            switch (option) {
                case 1 -> readSequential();
                case 2 -> readRandom();
                case 3 -> addAtTheEnd();
                case 4 -> replaceContact();
                case 5 -> modifyMoney();
                case 0 -> System.out.println("Fin del programa");
                default -> System.out.println("Opción no válida");
            }
        } while (option != 0);
    }

    // Opción 1: recorre el fichero de principio a fin
    private void readSequential() {
        try (RandomAccessFile reader = new RandomAccessFile(file.toFile(), "r")) {
            System.out.println("Lectura del fichero de manera secuencial:");
            while (reader.getFilePointer() < reader.length()) {
                int identifier = reader.readInt();
                System.out.printf("Contacto %d: %s%n", identifier, readContact(reader));
            }
        } catch (FileNotFoundException e) {
            System.err.printf("El fichero no existe: %s%n", e.getMessage());
        } catch (IOException e) {
            System.err.printf("Error de entrada/salida: %s%n", e.getMessage());
        }
    }

    // Opción 2: salta directamente al contacto elegido
    private void readRandom() {
        try (RandomAccessFile reader = new RandomAccessFile(file.toFile(), "r")) {
            int identifier = askIdentifier(reader, "consultar");
            if (identifier > 0) {
                reader.seek((long) (identifier - 1) * NUM_BYTES_CONTACT); // Comienzo del contacto
                System.out.printf("Contacto %d: %s%n", reader.readInt(), readContact(reader));
            }
        } catch (FileNotFoundException e) {
            System.err.printf("El fichero no existe: %s%n", e.getMessage());
        } catch (IOException e) {
            System.err.printf("Error de entrada/salida: %s%n", e.getMessage());
        }
    }

    // Opción 3: escribe un contacto nuevo por el final
    private void addAtTheEnd() {
        try {
            Files.createDirectories(file.getParent());
        } catch (IOException e) {
            System.err.printf("No se pudo crear la carpeta: %s%n", e.getMessage());
            return;
        }

        System.out.println("Vas a añadir un nuevo contacto por el final");
        Contact contact = askContact(); // Se piden los datos antes de abrir el fichero

        try (RandomAccessFile raf = new RandomAccessFile(file.toFile(), "rw")) {
            int last = calculateLastIndex(raf);
            raf.seek(raf.length()); // Se posiciona al final del fichero
            raf.writeInt(++last);
            writeContact(raf, contact);
            System.out.printf("Contacto añadido con el identificador %d%n", last);
        } catch (IOException e) {
            System.err.printf("Error de entrada/salida: %s%n", e.getMessage());
        }
    }

    // Opción 4: sustituye todos los datos de un contacto por otros
    private void replaceContact() {
        try (RandomAccessFile writer = new RandomAccessFile(file.toFile(), "rw")) {
            int identifier = askIdentifier(writer, "modificar");
            if (identifier > 0) {
                Contact contact = askContact();
                writer.seek((long) (identifier - 1) * NUM_BYTES_CONTACT);
                writer.skipBytes(IDENTIFIER); // Se salta el identificador porque es el mismo
                writeContact(writer, contact);
                System.out.println("Contacto modificado");
            }
        } catch (IOException e) {
            System.err.printf("Error de entrada/salida: %s%n", e.getMessage());
        }
    }

    // Opción 5: sobrescribe solo "si le debo dinero" y "cuánto"
    private void modifyMoney() {
        try (RandomAccessFile writer = new RandomAccessFile(file.toFile(), "rw")) {
            int identifier = askIdentifier(writer, "modificar el dinero");
            if (identifier > 0) {
                boolean moneyOwed = readBoolean("¿Le debes dinero? (s/n): ");
                double amountOwed = moneyOwed ? readDouble("¿Cuánto le debes?: ") : 0;
                writer.seek((long) (identifier - 1) * NUM_BYTES_CONTACT);
                writer.skipBytes(POSITION_MONEY_OWED); // Se coloca el puntero en el booleano
                writer.writeBoolean(moneyOwed);
                writer.writeDouble(amountOwed);
                System.out.println("Dinero modificado");
            }
        } catch (IOException e) {
            System.err.printf("Error de entrada/salida: %s%n", e.getMessage());
        }
    }

    // Lee el identificador del último contacto; 0 si el fichero está vacío
    private int calculateLastIndex(RandomAccessFile raf) throws IOException {
        if (raf.length() < NUM_BYTES_CONTACT) {
            return 0;
        }
        raf.seek(raf.length() - NUM_BYTES_CONTACT); // Se posiciona en el último contacto
        return raf.readInt();
    }

    // Muestra el rango válido y pide un identificador; devuelve 0 si no es válido
    private int askIdentifier(RandomAccessFile raf, String action) throws IOException {
        int lastIdentifier = calculateLastIndex(raf);
        if (lastIdentifier == 0) {
            System.out.println("La agenda está vacía. Añade antes un contacto.");
            return 0;
        }
        int identifier = readInt(String.format(
                "Introduce el identificador del contacto que quieres %s entre 1 y %d: ",
                action, lastIdentifier));
        if (identifier < 1 || identifier > lastIdentifier) {
            System.out.println("El identificador del contacto no es correcto.");
            return 0;
        }
        return identifier;
    }

    // Lee los campos de un contacto a partir de la posición actual del puntero (tras el id)
    private Contact readContact(RandomAccessFile reader) throws IOException {
        String name = readFixedString(reader, LEN_NAME);
        String phone = readFixedString(reader, LEN_PHONE);
        String address = readFixedString(reader, LEN_ADDRESS);
        int postalCode = reader.readInt();
        String birthDate = readFixedString(reader, LEN_BIRTH_DATE);
        boolean moneyOwed = reader.readBoolean();
        double amountOwed = reader.readDouble();
        return new Contact(name, phone, address, postalCode, birthDate, moneyOwed, amountOwed);
    }

    // Escribe los campos de un contacto a partir de la posición actual del puntero (tras el id)
    private void writeContact(RandomAccessFile writer, Contact contact) throws IOException {
        writeFixedString(writer, contact.getName(), LEN_NAME);
        writeFixedString(writer, contact.getPhone(), LEN_PHONE);
        writeFixedString(writer, contact.getAddress(), LEN_ADDRESS);
        writer.writeInt(contact.getPostalCode());
        writeFixedString(writer, contact.getBirthDate(), LEN_BIRTH_DATE);
        writer.writeBoolean(contact.isMoneyOwed());
        writer.writeDouble(contact.getAmountOwed());
    }

    private String readFixedString(RandomAccessFile reader, int length) throws IOException {
        char[] buffer = new char[length];
        for (int i = 0; i < length; i++) {
            buffer[i] = reader.readChar();
        }
        return new String(buffer).trim(); // trim quita el relleno
    }

    private void writeFixedString(RandomAccessFile writer, String text, int length)
            throws IOException {
        StringBuilder sb = new StringBuilder(text);
        sb.setLength(length); // Rellena o recorta para que ocupe siempre lo mismo
        writer.writeChars(sb.toString());
    }

    private Contact askContact() {
        String name = readText("\tNombre: ");
        String phone = readText("\tTeléfono: ");
        String address = readText("\tDirección: ");
        int postalCode = readInt("\tCódigo postal: ");
        String birthDate = readText("\tFecha de nacimiento (dd/MM/yyyy): ");
        boolean moneyOwed = readBoolean("\t¿Le debes dinero? (s/n): ");
        double amountOwed = moneyOwed ? readDouble("\t¿Cuánto le debes?: ") : 0;
        return new Contact(name, phone, address, postalCode, birthDate, moneyOwed, amountOwed);
    }

    // Métodos de lectura de teclado: repiten la pregunta hasta que el dato es válido

    private String readText(String prompt) {
        System.out.print(prompt);
        return keyboard.nextLine().trim();
    }

    private int readInt(String prompt) {
        while (true) {
            try {
                return Integer.parseInt(readText(prompt));
            } catch (NumberFormatException e) {
                System.out.println("Introduce un número entero válido.");
            }
        }
    }

    private double readDouble(String prompt) {
        while (true) {
            try {
                // Se admite la coma decimal (12,50) además del punto
                return Double.parseDouble(readText(prompt).replace(',', '.'));
            } catch (NumberFormatException e) {
                System.out.println("Introduce un número decimal válido.");
            }
        }
    }

    private boolean readBoolean(String prompt) {
        while (true) {
            String answer = readText(prompt).toLowerCase();
            if (answer.equals("s")) {
                return true;
            }
            if (answer.equals("n")) {
                return false;
            }
            System.out.println("Responde s o n.");
        }
    }

    public static void main(String[] args) {
        new Ejercicio1().show();
    }
}
```

### Explicación paso a paso

1. **`Constants` guarda el diseño del registro**, como la clase `Constants` de la teoría. Los tamaños se calculan **a partir de las longitudes** en vez de escribir `207` a mano: si mañana el nombre pasa a 40 caracteres, todo se recalcula solo. El constructor privado impide crear objetos de una clase que solo tiene constantes, y `import static … Constants.*` permite escribir `NUM_BYTES_CONTACT` sin poner delante `Constants.`.
2. **`Contact` no guarda el identificador**: el id es la posición del contacto en el fichero, así que lo escribe y lo lee `Ejercicio1`.
3. **Opción 1 (`readSequential`)**: recorre el fichero mientras `getFilePointer() < length()`, igual que `AccessSequential`. Cada vuelta lee el `int` del id y después el resto del contacto con `readContact`.
4. **Opción 2 (`readRandom`)**: `askIdentifier` muestra el rango válido (`entre 1 y N`) y comprueba la respuesta. Después, `seek((id - 1) * 207)` salta al principio del contacto. El `(long)` evita que la multiplicación desborde un `int` en ficheros muy grandes, porque `seek` recibe un `long`.
5. **`calculateLastIndex`**: se coloca en `length() - 207` (el principio del último contacto) y lee su id, como en `ReadRandom`. Si el fichero está vacío o es más corto que un contacto, devuelve `0`, y así la primera vez el nuevo id es `1`.
6. **Opción 3 (`addAtTheEnd`)**: primero pide los datos y luego abre el fichero en `"rw"`, que lo crea si no existe. Calcula el último id, pone el puntero al final con `seek(length())` y escribe `++last` y el contacto. Como en `AddAtTheEnd`, `RandomAccessFile` **sobrescribe** donde esté el puntero: para añadir, hay que llevarlo al final a mano.
7. **Opción 4 (`replaceContact`)**: va al principio del contacto, salta el id con `skipBytes(IDENTIFIER)` (el id no cambia) y sobrescribe los demás campos. Como el registro mide siempre 207 bytes, el contacto nuevo cabe justo en el hueco del viejo y no pisa al siguiente.
8. **Opción 5 (`modifyMoney`)**: va al principio del contacto y salta `POSITION_MONEY_OWED` (198 bytes) hasta el booleano. Solo se escriben el `boolean` y el `double`, que van seguidos: el resto del contacto no se toca.
9. **`writeFixedString` / `readFixedString`**: `setLength(30)` deja la cadena en 30 caracteres exactos. Si es más corta, la rellena con el carácter nulo `'\u0000'`. Si es más larga, la recorta. Al leer, `trim()` quita ese relleno, porque `trim` elimina cualquier carácter con código ≤ espacio, también el nulo.

> [!warning] El relleno no son espacios
> La teoría dice que las cadenas cortas "se rellenan con espacios". En realidad `setLength` rellena con `'\u0000'` (el carácter nulo), aunque el resultado es el mismo porque `trim()` también lo quita.

> [!tip] Prueba
> 1. Opción **1** sin fichero → "El fichero no existe".
> 2. Opción **3** dos veces (Ana y un nombre de más de 30 caracteres) → ids 1 y 2. El fichero ocupa **414 bytes** (2 × 207) y el nombre largo aparece recortado a 30 caracteres.
> 3. Opción **2** con el id `9` → "El identificador del contacto no es correcto". Con el `2`, muestra ese contacto.
> 4. Opción **4** sobre el 1 y opción **5** sobre el 2 (`s`, `99,99`) → la opción 1 muestra el contacto 1 cambiado entero y el 2 con solo el dinero cambiado.

## Esquema comparativo de conceptos clave

| Necesidad | API utilizada | Idea principal |
| --- | --- | --- |
| Que todos los contactos ocupen lo mismo | `StringBuilder.setLength` + `writeChars` | Cadenas de longitud fija: 2 bytes por carácter. |
| Ir al contacto `id` | `seek((long) (id - 1) * NUM_BYTES_CONTACT)` | Posición = (id − 1) × tamaño del registro. |
| Conocer el rango de ids válidos | `seek(length() - NUM_BYTES_CONTACT)` + `readInt` | El último registro guarda el id más alto. |
| Añadir por el final | `seek(length())` + `write…` | `RandomAccessFile` sobrescribe donde esté el puntero. |
| Cambiar solo una parte del registro | `skipBytes(IDENTIFIER)` / `skipBytes(POSITION_MONEY_OWED)` | Se salta lo que no cambia y se sobrescribe el resto. |
| Recorrer todo el fichero | `while (getFilePointer() < length())` | El final es cuando el puntero llega a la longitud. |
