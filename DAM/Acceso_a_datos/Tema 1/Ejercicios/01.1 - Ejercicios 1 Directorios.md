## Ejercicio 1: Metadatos y propiedades de un fichero

> [!question] Enunciado
> Dado un fichero que se encuentre en una subcarpeta de tu directorio actual, muestra su nombre, si es un ejecutable, si está oculto, la ruta relativa, la ruta absoluta y el tamaño.

### Clases y métodos introducidos
- `Path` y `Paths.get(...)`: representan y construyen rutas de forma independiente del sistema operativo.
- `Files.isExecutable`, `Files.isHidden` y `Files.size`: consultan propiedades del fichero en el sistema de archivos.
- `Path.getFileName()` y `Path.toAbsolutePath()`: obtienen el nombre y la ruta absoluta.

> **Términos explicados:** [[01 - Ficheros#2. La interfaz Path|`Path` y rutas relativas/absolutas]] · [[01 - Ficheros#2.2 Crear un objeto Path: Paths.get()|`Paths.get()`]] · [[01 - Ficheros#3. La clase Files|metadatos y propiedades del sistema de archivos]]

#### Ejemplo simple de funcionamiento
```java
Path file = Paths.get("datos", "prueba.txt");
System.out.println("Nombre: " + file.getFileName());
System.out.println("Ruta absoluta: " + file.toAbsolutePath());
System.out.println("Tamaño: " + Files.size(file) + " bytes");
```

### Conceptos clave
- `Paths.get("carpeta", "fichero.ext")`: construye la ruta relativa independiente del SO.
- `file.getFileName()`: extrae únicamente el nombre del archivo (el último componente de la ruta).
- `file.toAbsolutePath()`: resuelve la ruta completa desde la raíz del sistema de archivos.
- `Files.isExecutable(file)`: comprueba permisos de ejecución en el sistema operativo.
- `Files.isHidden(file)`: consulta si el archivo está oculto (en Linux si empieza por `.`, en Windows por atributo oculto).
- `Files.size(file)`: devuelve el tamaño en bytes como `long`.
- Excepciones: `NoSuchFileException` (si el archivo no existe) e `IOException` (error general de E/S).

### Código (`Ejercicio1.java`)

```java
package ejercicios1_Directorios;

import java.io.IOException;
import java.nio.file.*;

public class Ejercicio1 {

    public void show() {
        Path file;
        try {
            // La ruta es relativa al directorio de trabajo del proyecto.
            file = Paths.get("datos", "prueba.txt");

            // getFileName y toAbsolutePath consultan la representación de la ruta.
            System.out.printf("El nombre del path es: %s\n", file.getFileName());
            System.out.printf("La ruta relativa es: %s\n", file);
            System.out.printf("La ruta absoluta es: %s\n", file.toAbsolutePath());

            // Estos métodos consultan propiedades del fichero en el sistema operativo.
            System.out.printf("¿Es ejecutable?: %s\n", Files.isExecutable(file) ? "Si" : "No");
            System.out.printf("¿Está oculto?: %s\n", Files.isHidden(file));
            System.out.printf("El tamaño del fichero es: %s\n", Files.size(file));

        } catch (NoSuchFileException e) {
            // Se captura antes porque es más específica que IOException.
            System.err.printf("El fichero no existe: %s", e.getMessage());
        } catch (IOException e) {
            System.err.printf("Error de entrada/salida: %s", e.getMessage());
        }
    }

    public static void main(String[] args) {
        new Ejercicio1().show();
    }
}
```

### Explicación paso a paso
1. **Definir la ruta:** Se crea el objeto `Path` con `Paths.get("datos", "prueba.txt")`, apuntando a un archivo relativo al directorio de ejecución.
2. **Obtener metadatos con `Path`:** Métodos directos del propio objeto `Path` sin tocar el disco (`getFileName()`, `toAbsolutePath()`, y el propio objeto para la relativa).
3. **Obtener propiedades con `Files`:** Se invoca a `Files.isExecutable`, `Files.isHidden` y `Files.size`, que acceden al sistema de archivos para consultar atributos reales.
4. **Control de excepciones:** Es obligatorio envolver en `try-catch` capturando primero `NoSuchFileException` (específica) y luego `IOException` (genérica).

## Ejercicio 2: Crear, renombrar, borrar y listar estructura

> [!question] Enunciado
> Crea un directorio en el directorio actual, luego crea tres ficheros en dicho directorio donde uno se borre y otro se renombre. Crear también un subdirectorio con un fichero dentro. Después mostrar la ruta absoluta de ambos directorios y sus contenidos.

### Clases y métodos introducidos
- `Files.createDirectory` y `Files.createFile`: crean directorios y ficheros.
- `Path.resolve`: compone rutas hijas a partir de una ruta base.
- `Files.deleteIfExists` y `Files.move`: eliminan y renombran/mueven elementos.
- `Files.list` y `Stream<Path>`: enumeran el contenido inmediato de un directorio.

> **Términos explicados:** [[01 - Ficheros#Combinando rutas: resolve()|`resolve`]] · [[01 - Ficheros#5.1 try-with-resources|`try-with-resources` y cierre automático]] · [[01 - Ficheros#5. Listar elementos de un directorio|`Files.list` y `Stream<Path>`]]

#### Ejemplo simple de funcionamiento
```java
Path directory = Paths.get("datos");
Files.createDirectories(directory);
Path file = directory.resolve("ejemplo.txt");
Files.createFile(file);
System.out.println(file.toAbsolutePath());
```

### Conceptos clave
- `Files.exists(path)`: comprobación previa para evitar excepciones innecesarias.
- `dir.resolve("nombre")`: une una ruta base con un subelemento de forma limpia y multiplataforma.
- `Files.createDirectory(path)` y `Files.createFile(path)`: creación de carpetas y ficheros vacíos.
- `Files.deleteIfExists(path)`: borra sin lanzar excepción si el archivo no estuviese.
- `Files.move(origen, destino)`: renombra al estar en el mismo directorio base.
- `Files.list(directorio)`: devuelve un `Stream<Path>` con el contenido inmediato del directorio (1 nivel).
- `try-with-resources`: asegura que el stream devuelto por `Files.list` se cierre y libere los recursos del sistema operativo.

### Código (`Ejercicio2.java`)

```java
package ejercicios1_Directorios;

import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.NotDirectoryException;
import java.nio.file.Path;
import java.nio.file.Paths;
import java.util.stream.Stream;

public class Ejercicio2 {
    public void show() {
        try {
            // Prepara la carpeta principal solo si todavía no existe.
            Path dirPrincipal = Paths.get("datos2");
            if (!Files.exists(dirPrincipal)) {
                Files.createDirectory(dirPrincipal);
            }

            // resolve compone rutas hijas sin concatenar separadores manualmente.
            Path fichero1 = dirPrincipal.resolve("fichero1.txt");
            Path fichero2 = dirPrincipal.resolve("fichero2.txt");
            Path fichero3 = dirPrincipal.resolve("fichero3.txt");

            // createFile falla si ya existe; por eso se comprueba antes.
            if (!Files.exists(fichero1)) {
                Files.createFile(fichero1);
            }
            if (!Files.exists(fichero2)) {
                Files.createFile(fichero2);
            }
            if (!Files.exists(fichero3)) {
                Files.createFile(fichero3);
            }

            // Borrado del fichero 1
            Files.deleteIfExists(fichero1);

            // Renombrado del fichero 2
            Path ficheroRenombrado = dirPrincipal.resolve("fichero_renombrado");
            if (!Files.exists(ficheroRenombrado)) {
                Files.move(fichero2, ficheroRenombrado);
            }

            // Creación de subdirectorio con fichero interno
            Path subdirectorio = dirPrincipal.resolve("subdirectorio");
            if (!Files.exists(subdirectorio)) {
                Files.createDirectory(subdirectorio);
            }

            Path ficheroSub = subdirectorio.resolve("ficheroSub");
            if (!Files.exists(ficheroSub)) {
                Files.createFile(ficheroSub);
            }

            // Mostrar resultados de ambos directorios
            mostrarDetallesDelDirectorio(dirPrincipal);
            mostrarDetallesDelDirectorio(subdirectorio);
        } catch (IOException e) {
            System.err.printf("Error al mostrar el contenido del directorio: %s", e.getMessage());
        }
    }

    private void mostrarDetallesDelDirectorio(Path directorio) throws IOException {
        // Muestra primero la ruta completa del directorio que se va a listar.
        System.out.println(directorio.toAbsolutePath());

        // Files.list solo recorre un nivel; try-with-resources cierra el Stream al terminar.
        try (Stream<Path> directoryContents = Files.list(directorio)) {
            directoryContents.forEach(content -> System.out.println(content.getFileName()));
        } catch (NotDirectoryException e) {
            System.err.printf("El directorio no existe: %s", e.getMessage());
        } catch (IOException e) {
            System.err.printf("Error al mostrar el contenido del directorio: %s", e.getMessage());
        }
    }

    public static void main(String[] args) {
        new Ejercicio2().show();
    }
}
```

### Explicación paso a paso
1. **Construir jerarquía con `resolve`:** En lugar de concatenar cadenas con `+` o barras, se usa `dirPrincipal.resolve("fichero1.txt")`.
2. **Crear y alterar archivos:**
   - Se crean `fichero1`, `fichero2` y `fichero3`.
   - `Files.deleteIfExists(fichero1)` elimina el primero sin peligro de fallar si ya no existiera.
   - `Files.move(fichero2, ficheroRenombrado)` traslada el fichero dentro de la misma carpeta, funcionando como renombrado.
3. **Crear subdirectorio:** `dirPrincipal.resolve("subdirectorio")` y dentro `subdirectorio.resolve("ficheroSub")`.
4. **Listar contenidos:** El método auxiliar `mostrarDetallesDelDirectorio` imprime la ruta absoluta y recorre el contenido con `Files.list(directorio)` dentro de un `try-with-resources` para evitar fugas de descriptores de fichero.

## Ejercicio 3: Listado recursivo manual sin Files.walk

> [!question] Enunciado
> Muestra el nombre y tipo (fichero o directorio) de los ficheros y subdirectorios contenidos en un directorio solicitado al usuario. Muestra también el contenido de todos los subdirectorios y si estos contienen subdirectorios también... y así sucesivamente hasta mostrar todo el contenido de dicho directorio. **No se puede utilizar el método walk de la clase Files.**

### Clases y métodos introducidos
- `Scanner`: lee la ruta introducida por consola.
- `Files.list`: enumera un nivel del árbol de directorios.
- `Files.isDirectory`: permite decidir si se debe descender recursivamente.
- Recursividad: visita subdirectorios hasta agotar los niveles.

> **Términos explicados:** [[#Ejercicio 3: Listado recursivo manual sin Files.walk|recursividad, caso base y recorrido en profundidad]] · [[01 - Ficheros#5. Listar elementos de un directorio|`Files.list`]]

#### Ejemplo simple de funcionamiento
```java
private void listar(Path directory) throws IOException {
    try (Stream<Path> contents = Files.list(directory)) {
        contents.forEach(path -> {
            System.out.println(path.getFileName());
            if (Files.isDirectory(path)) {
                try {
                    listar(path);
                } catch (IOException e) {
                    System.err.println(e.getMessage());
                }
            }
        });
    }
}
```

### Conceptos clave
- **Recursividad:** Una función que se llama a sí misma cuando encuentra un elemento que es a su vez un directorio.
- `Files.list(directorio)`: lista un solo nivel; combinado con recursividad manual permite descender niveles sin `Files.walk`.
- `Files.isDirectory(path)`: condición de parada/ramificación para saber si invocar recursivamente o solo imprimir.
- Formato de salida con `printf`: uso de `%-13s %s\n` para alinear columnas entre `[DIRECTORIO]` y `[FICHERO]`.

### Código (`Ejercicio3.java`)

```java
package ejercicios1_Directorios;

import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.NotDirectoryException;
import java.nio.file.Path;
import java.nio.file.Paths;
import java.util.Scanner;
import java.util.stream.Stream;

public class Ejercicio3 {
    public void show() {
        try {
            // Scanner lee la ruta escrita por el usuario en la consola.
            Scanner sc = new Scanner(System.in);

            System.out.print("Introduce el nombre del directorio a explorar: ");
            Path directorio = Paths.get(sc.nextLine().trim());

            // Comprueba si la ruta es un directorio antes de iniciar el recorrido recursivo.
            System.out.printf("El directorio %s existe: %s\n", directorio, Files.isDirectory(directorio) ? "Si" : "No");
            mostrarDatos(directorio);

        } catch (IOException e) {
            System.err.printf("Error al mostrar el contenido del directorio: %s", e.getMessage());
        }
    }

    private void mostrarDatos(Path directorio) throws IOException {
        // Cada llamada lista un nivel; las llamadas recursivas visitan los niveles inferiores.
        try (Stream<Path> directoryContents = Files.list(directorio)) {
            directoryContents.forEach(content -> {
                // Clasifica cada ruta antes de imprimirla.
                boolean esDir = Files.isDirectory(content);
                String tipo = esDir ? "[DIRECTORIO]" : "[FICHERO]";

                System.out.printf("%-13s %s\n", tipo, content.getFileName());
                if (esDir) {
                    try {
                        mostrarDatos(content); // Llamada recursiva para explorar la subcarpeta
                    } catch (IOException e) {
                        System.err.printf("Error al entrar al subdirectorio %s: %s\n", content.getFileName(), e.getMessage());
                    }
                }
            });
        } catch (NotDirectoryException e) {
            System.err.printf("No es un directorio: %s\n", e.getMessage());
        } catch (IOException e) {
            System.err.printf("Error al mostrar el contenido del directorio: %s\n", e.getMessage());
        }
    }

    public static void main(String[] args) {
        new Ejercicio3().show();
    }
}
```

### Explicación paso a paso
1. **Entrada de usuario:** Se lee por consola la ruta que se desea inspeccionar con `Scanner`.
2. **Caso base y ramificación:** En `mostrarDatos`, se abre un stream con `Files.list(directorio)`.
3. **Clasificación:** Para cada elemento se comprueba `Files.isDirectory(content)`.
4. **Paso recursivo:** Si `esDir == true`, se vuelve a llamar a `mostrarDatos(content)`. Al procesarse en profundidad, se recorre el árbol completo sin necesitar `Files.walk`.
5. **Cierre de recursos:** Cada nivel abre su propio `try-with-resources`, garantizando que todos los streams se cierren correctamente al subir en la pila de llamadas.

## Ejercicio 4: Filtrar archivos .java recursivamente con Files.walk

> [!question] Enunciado
> Muestra todos los archivos con extensión `.java` que se encuentren en un directorio y sus subdirectorios.

### Clases y métodos introducidos
- `Files.walk`: produce un `Stream<Path>` con rutas de todo el árbol, incluidos subdirectorios.
- `Files.isRegularFile`: filtra ficheros regulares y descarta directorios.
- `Path.getFileName` y `String.endsWith`: permiten comprobar la extensión del nombre.

> **Términos explicados:** [[01 - Ficheros#5.2 Files.walk — recorrido recursivo|recorrido recursivo con `Files.walk`]] · [[01 - Ficheros#5. Listar elementos de un directorio|`Stream<Path>` y cierre de recursos]] · [[01 - Ficheros#3. La clase Files|`Files.isRegularFile`]]

#### Ejemplo simple de funcionamiento
```java
try (Stream<Path> paths = Files.walk(Paths.get("."))) {
    paths.filter(Files::isRegularFile)
            .filter(path -> path.getFileName().toString().endsWith(".java"))
            .forEach(System.out::println);
}
```

### Conceptos clave
- `Files.walk(directory)`: recorre de forma recursiva (profundidad indeterminada) todo el árbol de directorios a partir de la raíz dada.
- `Stream.filter(...)`: encadenamiento de filtros funcionales.
- `Files::isRegularFile`: método por referencia para descartar carpetas que pudieran llamarse con punto o terminar en `.java`.
- `path.getFileName().toString().toLowerCase().endsWith(".java")`: verificación robusta de la extensión ignorando mayúsculas/minúsculas.

### Código (`Ejercicio4.java`)

```java
package ejercicios1_Directorios;

import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.NotDirectoryException;
import java.nio.file.Path;
import java.nio.file.Paths;
import java.util.stream.Stream;

public class Ejercicio4 {
    public void show() {

        // El punto representa el directorio de trabajo desde el que se ejecuta el programa.
        Path directory = Paths.get(".");

        // Files.walk recorre también todos los subdirectorios y el Stream se cierra al salir.
        try (Stream<Path> directoryContents = Files.walk(directory)) {
            directoryContents
                    // Descarta directorios y conserva solo ficheros regulares.
                    .filter(Files::isRegularFile)
                    // Compara la extensión sin distinguir mayúsculas y minúsculas.
                    .filter(p -> p.getFileName().toString().toLowerCase().endsWith(".java"))
                    .forEach(System.out::println);
        } catch (NotDirectoryException e) {
            System.err.printf("El directorio no existe: %s", e.getMessage());
        } catch (IOException e) {
            System.err.printf("Error al mostrar el contenido del directorio: %s", e.getMessage());
        }

    }

    public static void main(String[] args) {
        new Ejercicio4().show();
    }
}
```

### Explicación paso a paso
1. **Origen:** `Paths.get(".")` toma el directorio de trabajo del proyecto como raíz.
2. **Generar stream recursivo:** `Files.walk(directory)` genera una secuencia con todas las rutas del árbol.
3. **Filtrar:**
   - `.filter(Files::isRegularFile)` descarta carpetas y enlaces simbólicos.
   - `.filter(p -> p.getFileName().toString().toLowerCase().endsWith(".java"))` se asegura de que el nombre del fichero acabe en `.java` (en minúsculas para compatibilidad entre sistemas).
4. **Impresión:** `forEach(System.out::println)` imprime cada ruta encontrada.

## Ejercicio 5: Borrado recursivo completo de un directorio

> [!question] Enunciado
> Eliminar un directorio y todo su contenido (archivos y subdirectorios).

### Clases y métodos introducidos
- `Files.exists`: comprueba si la ruta indicada existe.
- `Files.walk`: recoge la raíz y todos sus descendientes.
- `Comparator.reverseOrder`: ordena las rutas para borrar primero elementos profundos.
- `Files.delete`: elimina cada elemento; los directorios deben estar vacíos.

> **Términos explicados:** [[#Ejercicio 5: Borrado recursivo completo de un directorio|borrado de hojas antes que directorios y recorrido inverso]] · [[01 - Ficheros#3. La clase Files|`Files.delete` y directorio no vacío]] · [[01 - Ficheros#5.2 Files.walk — recorrido recursivo|`Files.walk`]]

#### Ejemplo simple de funcionamiento
```java
try (Stream<Path> paths = Files.walk(directory)) {
    paths.sorted(Comparator.reverseOrder()).forEach(path -> {
        try {
            Files.delete(path);
        } catch (IOException e) {
            System.err.println("No se pudo eliminar " + path + ": " + e.getMessage());
        }
    });
}
```

### Conceptos clave
- **Limitación de `Files.delete`:** Java prohíbe eliminar un directorio si no está vacío (`DirectoryNotEmptyException`).
- **Orden de borrado:** Es obligatorio borrar primero las hojas (los archivos y subcarpetas más profundas) antes de poder borrar la carpeta contenedora.
- `Comparator.reverseOrder()`: al ordenar un stream de `Files.walk` en orden inverso, las rutas más profundas y los ficheros quedan al principio, y la carpeta raíz queda al final.

### Código (`Ejercicio5.java`)

```java
package ejercicios1_Directorios;

import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;
import java.util.Comparator;
import java.util.stream.Stream;

public class Ejercicio5 {

    public void show() {
        Path directorioABorrar = Paths.get("directorio_para_borrar");

        // Evita iniciar el recorrido si la ruta indicada no existe.
        if (!Files.exists(directorioABorrar)) {
            System.out.println("El directorio no existe: " + directorioABorrar.toAbsolutePath());
            return;
        }

        // walk incluye la carpeta raíz y todos sus descendientes.
        try (Stream<Path> stream = Files.walk(directorioABorrar)) {
            stream
                    // El orden inverso coloca los elementos más profundos antes que sus padres.
                    .sorted(Comparator.reverseOrder())
                    .forEach(path -> {
                        try {
                            // Al borrar de abajo hacia arriba, cada directorio ya está vacío.
                            Files.delete(path);
                            System.out.println("Eliminado: " + path.getFileName());
                        } catch (IOException e) {
                            System.err.printf("No se pudo eliminar %s: %s\n", path, e.getMessage());
                        }
                    });

            System.out.println("Directorio y todo su contenido eliminados con éxito.");

        } catch (IOException e) {
            System.err.printf("Error al recorrer el directorio: %s\n", e.getMessage());
        }
    }

    public static void main(String[] args) {
        new Ejercicio5().show();
    }
}
```

### Explicación paso a paso
1. **Comprobación previa:** Si `!Files.exists(directorioABorrar)`, se avisa y se sale con `return` para no lanzar excepciones innecesarias.
2. **Generar el árbol:** `Files.walk(directorioABorrar)` genera todos los nodos del directorio, empezando por la raíz:
   ```
   directorio_para_borrar
   directorio_para_borrar/subcarpeta
   directorio_para_borrar/subcarpeta/archivo.txt
   ```
3. **Invertir el orden con `Comparator.reverseOrder()`:**
   ```
   directorio_para_borrar/subcarpeta/archivo.txt  --> 1º se borra el fichero
   directorio_para_borrar/subcarpeta              --> 2º la subcarpeta ya está vacía, se borra
   directorio_para_borrar                         --> 3º la raíz ya está vacía, se borra
   ```
4. **Borrado seguro:** `Files.delete(path)` en cada paso borra elementos que garantizadamente ya están vacíos o son ficheros regulares.

## Esquema comparativo de operaciones

| Operación | Método Java | Observación crítica |
| --- | --- | --- |
| Consultar propiedades | `Files.isExecutable`, `Files.size`, etc. | Requieren capturar `IOException` |
| Componer rutas | `path.resolve("sub")` | Siempre preferible a concatenar strings con `/` o `\` |
| Listar 1 nivel | `Files.list(dir)` | Rápido, no recursivo; requiere cerrar stream |
| Listar todo el árbol | `Files.walk(dir)` | Recursivo; primer elemento es la propia raíz |
| Borrar árbol completo | `Files.walk` + `sorted(Comparator.reverseOrder())` | Evita `DirectoryNotEmptyException` |
