# 04 · Reglas de nomenclatura en los ejercicios

> [!info] Asignatura
> [[DAM/Acceso_a_datos/Indice|Acceso a Datos]] · Normas de entrega de prácticas

Reglas para nombrar proyectos, paquetes y clases en los boletines de [[01 - Ficheros]] y resto de temas:

## Reglas

1. **Un proyecto por cada tema**, con el mismo nombre que el tema.
2. **Un paquete por cada boletín de ejercicios**, con el mismo nombre que el boletín.
3. **Una clase por cada ejercicio**, con el mismo nombre del ejercicio. Si el ejercicio contiene más de una clase, crear un **paquete para el ejercicio**.
4. Si hay más de un número, **separarlos con un guion bajo `_`**.
5. **No poner tildes**.

## Ejemplo ficticio

Nomenclatura del primer boletín de ejercicios llamado *"Ejercicios 1.1 Tipos de datos primitivos"* perteneciente al tema *"1. Introducción"*:

| Elemento | Nombre |
| --- | --- |
| Proyecto | `Tema1Introduccion` |
| Paquete | `ejercicios1_1TiposDeDatosPrimitivos` |
| Clases | `Ejercicio1`, `Ejercicio2`, `Ejercicio3`, `Ejercicio4`, `Ejercicio5`, `Ejercicio6` |

## Checklist antes de entregar

- [ ] ¿Un proyecto por tema con el nombre del tema?
- [ ] ¿Un paquete por boletín con el nombre del boletín?
- [ ] ¿Una clase por ejercicio (o paquete si tiene varias clases)?
- [ ] ¿Números separados por `_`?
- [ ] ¿Sin tildes?
