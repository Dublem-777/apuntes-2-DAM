## 1. Decisiones de diseño

App de ejemplo: **TaskFlow**, un gestor de tareas. Formulario en una sola columna, con barra superior «Crear cuenta» y botón de volver.

| Decisión | Motivo |
| --- | --- |
| Etiqueta visible siempre encima del campo | El placeholder desaparece al escribir; la etiqueta no |
| Placeholder con un ejemplo real (`nombre@ejemplo.com`) | Enseña el formato esperado |
| Teclado según el dato (`email`, `tel`, `numeric`) | Menos errores y menos pulsaciones en el móvil |
| Texto de ayuda gris bajo cada campo | Explica qué se pide **antes** de que haya error |
| Validación al salir del campo y al pulsar «Crear cuenta» | No se marca error mientras el usuario aún escribe |
| Error = borde rojo + fondo + «!» + icono ⚠ + texto | No depende solo del color (accesibilidad) |
| Mensaje de error concreto («has escrito 7») | Dice cómo arreglarlo, no solo que está mal |
| Aviso general arriba al enviar con errores | El usuario sabe que tiene que revisar |
| Barra de fuerza y lista de requisitos de contraseña | Feedback inmediato mientras escribe |
| Campo opcional marcado como *(opcional)* | El resto se entiende obligatorio (nota al principio) |
| Campos de 52 px y botón de 52 px | Zona táctil cómoda (≥ 48 px) |
| Pantalla de éxito con siguiente paso | Cierra el flujo y dice qué hacer ahora |

> [!tip] Ayuda vs error
> La ayuda es **gris** y aparece desde el principio. Cuando el campo falla, el mensaje de ayuda se **sustituye** por el error en rojo en el mismo sitio, así la pantalla no salta.

## 2. Reglas de validación y mensajes

| Campo | Ayuda | Errores posibles |
| --- | --- | --- |
| Nombre y apellidos | Tal y como aparece en tu documento de identidad | Vacío · contiene números · falta apellido |
| Correo electrónico | Te enviaremos un enlace para confirmar la cuenta | Vacío · formato no válido (sin `@`, sin dominio, con espacios) |
| Teléfono *(opcional)* | 9 dígitos. Solo lo usaremos para recuperar tu cuenta | Letras o símbolos · número de dígitos distinto de 9 |
| Fecha de nacimiento | Debes tener al menos 14 años | Vacía · formato o fecha inexistente (31/02) · futura · menor de 14 años |
| Contraseña | Mín. 8 caracteres con mayúscula, número y símbolo | Vacía · demasiado débil (requisitos en rojo) |
| Repite la contraseña | Debe coincidir con la contraseña anterior | Vacía · no coincide |
| Términos | — | Sin aceptar |

## Esquema

| Estado del campo | Aspecto | Mensaje |
| --- | --- | --- |
| Sin tocar | Borde gris | Ayuda gris |
| Con foco | Borde azul + halo | Ayuda gris (y requisitos en contraseña) |
| Correcto | Borde verde + ✓ | Ninguno |
| Error | Borde y fondo rojos + «!» | ⚠ + texto del error en rojo |
